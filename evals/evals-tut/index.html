Understanding LLM Evals

How do you know whether an AI system works? Not "feels good in a demo" works — measurably, repeatably, and credibly works. This course teaches evaluation from the ground up: the process, the statistics, the failure modes of the measurements themselves, and the tools. No ML or statistics background assumed.

The premise of this course

Evaluation is measurement, and measurement is a discipline. A score is a claim about the world, and like any claim it can be wrong — because the test data leaked into training, because the grader is biased, because the difference is statistical noise, or because the number measures something other than what you care about. Learning evals means learning both how to build them and how to distrust them properly.

What you'll be able to do

  • Take a vague complaint ("the bot is sometimes weird") and turn it into a reproducible, measurable failure mode.
  • Build evaluators — code checks, human labeling workflows, and LLM judges — and validate the evaluators themselves.
  • Read any benchmark's scoring harness critically and predict how its numbers can mislead.
  • Put honest error bars on a score and tell a real improvement from noise.
  • Recognize contamination, judge bias, and leaderboard distortions before they cost you a decision.
  • Use a real eval harness (Inspect) and navigate the surrounding tool ecosystem.

How to use this course

The modules build on each other, and the recommended path is simply in order — but each page is written to stand alone, wiki-style, with cross-links wherever it leans on another page. If you're here with a specific question ("is this benchmark score trustworthy?" → Module 6; "my judge disagrees with me" → Module 3; "has this neuron really been explained?" → Module 8), jump straight in and follow links backward as needed.

Statistical concepts are explained in plain language where they appear, with a link to the appendix that teaches the underlying math properly. You can read the whole course without the appendices, but Module 5 will reward you for reading Appendix B first.

A note on provenance

This course practices what it teaches. Every empirical claim — every number, finding, and quoted position — was verified against its primary source (the actual paper or documentation, fetched and checked) before being written down, and carries an inline citation like [GSM1k] linking to that source. Each page ends with a source box. A course about rigorous measurement that cited summaries-of-summaries would fail its own first lesson.
