Reference

Glossary

Definitions in the language of the course. Linked terms in lessons also show keyboard-accessible tooltips.

Ablation

Removing a component’s contribution (setting it to zero or to a mean) and measuring the change in the output.

Activation

The value of a unit on a given input. For a neuron, a scalar per token or per image position.

Activation cache

A dictionary from hook-point names to the activations recorded during one forward pass.

Activation patching

Running a corrupted input while replacing one activation with its value from a clean input, to measure how much of the clean behaviour that activation restores.

Attention head

One of several parallel units in an attention layer, each computing a pattern of weights over earlier positions and moving information along it.

Attention pattern

The matrix of weights a head assigns from each query position to each key position; rows sum to one.

Attribution graph

A diagram of which components contributed to an output, built by tracing contributions backward from the output through the network.

Base rate

How often the property the explanation names occurs in the data. It bounds what accuracy and correlation can achieve and must be reported beside them.

Clean/corrupted pair

Two inputs that differ in one respect the claim is about, with different expected outputs, used for patching.

Control

A comparison that would also pass if the claim were empty: a random neuron, shuffled labels, a baseline explanation, a rotated stimulus. The claim must beat its controls.

Correlation

The Pearson coefficient between two series: 1 means a perfect linear match, 0 no linear relation, −1 a perfect inverse match.

Correlational evidence

Evidence that a unit’s activity co-varies with a property. It supports “represents”; it does not support “is used for”.

Demonstrated explanation

An explanation that predicted the component’s behaviour on data chosen before the look, beat its controls, and met a threshold fixed in advance.

Direct logit attribution

Decomposing a logit into the contributions of each component’s output projected onto the target token’s unembedding row, through the final layer norm.

Direction

A unit vector in activation space. Projecting activations onto it gives a scalar; a probe or a feature is a direction with a claim attached.

Downstream KL

The divergence between the model’s output distribution with a unit’s true activations and with simulated ones substituted. It measures whether the simulation errors matter to the model.

Explanation

A claim that a model component (neuron, direction, head, feature) responds to, or computes, something nameable. Until tested it is a hypothesis.

Explanation score

The correlation between simulated and true activations, as used by Bills et al. (2023). Its value depends heavily on which text excerpts it is computed on.

Feature

A direction or unit claimed to correspond to one meaningful property of the input. Used both for native neurons and for learned dictionary elements.

Feature visualization

Optimising an input image by gradient ascent to maximise a unit’s activation. Shows what excites the unit; does not show how often that occurs in real data.

Held-out data

Inputs that played no part in forming or choosing the explanation. Scores on them are the only ones that cannot be inflated by selection.

Hook point

A named location in the forward pass where an activation can be read or replaced, such as blocks.5.hook_resid_post.

In-context learning

A model predicting later tokens better because of earlier tokens in the same context, measured by the drop in loss along the sequence.

Induction head

An attention head that, on a repeated sequence, attends from a token to the token that followed its earlier occurrence and raises that token’s logit: the rule [A][B]…[A] → [B].

Interventional evidence

Evidence from changing a unit and observing the output. It supports causal claims about what the unit does for the model.

Linear probe

A classifier fitted on activations to predict a label. High held-out accuracy shows the label is linearly readable from the activations; it does not show the model uses it.

Logit lens

Applying the model’s final layer norm and unembedding to the residual stream after an intermediate block, to read what the block’s state would predict if it were the last.

Max-activating examples

The inputs on which a unit fires most strongly. They are the first thing to look at and the easiest thing to be misled by.

MLP

The feed-forward block of a transformer layer: a linear map up to a wider hidden layer, a nonlinearity, and a linear map back.

Monosemantic

Responding to one nameable thing. A claim of monosemanticity needs the same prediction test as any other explanation.

Multiple comparisons

Testing many candidates and reporting the best. The best of n meaningless scores is not meaningless-looking; held-out data and corrected thresholds are the remedies.

Native neuron

A neuron of the network as trained, studied directly, as opposed to a learned feature produced by a second model such as a sparse autoencoder.

Negative result

A pre-registered test that failed. Reported with the same detail as a success, it is a contribution; hidden, it is the reason the field cannot trust the successes.

Neuron

One coordinate of an activation vector; in a transformer MLP, one hidden unit after its nonlinearity; in a convolutional network, one channel of a feature map.

Orientation selectivity

How concentrated a tuning curve is around one orientation; the course uses the vector strength of the response over the circle, 0 flat to 1 single-angle.

Polysemantic neuron

A neuron that responds to several apparently unrelated inputs. Whether a given case is truly unrelated, or one concept nobody has named, is an empirical question.

Pre-registration

Writing the prediction, the data it will be scored on, the scoring function, the controls, and the pass threshold before running the test.

Precision and recall

For an explanation read as a predicate: precision is the fraction of inputs matching the predicate on which the unit fires; recall is the fraction of inputs where the unit fires that match the predicate.

Prediction test

A procedure that turns an explanation into a number on held-out data: for example the correlation between activations predicted from the explanation and the activations actually observed.

Prefix-matching score

On a repeated random sequence, the mean attention from each second-copy token to the token after its first-copy occurrence.

Quantile sampling

Drawing random examples from fixed bands of the unit’s activation distribution, so that weak and typical activations are seen as well as the strongest.

Random-neuron control

Scoring the same explanation against randomly chosen other units. It measures how much of the score comes from the explanation fitting the data rather than the unit.

Receptive field

The region of the input that can influence one position of a convolutional feature map.

Replication

Repeating a published test on new data, a new model copy, or new stimuli, with the test fixed in advance, and reporting what did and did not hold.

Residual stream

The vector each transformer block reads from and adds to; the sum of the embeddings and every block’s attention and MLP outputs so far.

SAE feature

One latent of a sparse autoencoder: a direction and a sparse activation. Its explanation is scored the same way a neuron’s is.

Screening split

The portion of data used to search for candidates and form hypotheses. Any score computed on it is biased upward by the search.

Selection bias

The upward distortion of a score when the thing scored was chosen because it scored well. Searching many units and reporting the best one is the common case.

Shuffled-label control

Scoring the unit against a permutation of the explanation’s predictions. It gives the distribution of scores a meaningless explanation would get.

Simulation scoring

Having a simulator (a model or a rule) predict a unit’s activation on each token from the explanation alone, then scoring the predictions against the true activations.

Sparse autoencoder

A second model trained to reconstruct activations from a sparse, overcomplete set of learned directions. Its latents are offered as more interpretable features than neurons.

Superposition

The hypothesis that a network represents more features than it has neurons by spreading features across neurons, so single neurons mix features.

Synthetic stimulus

A rendered input with known parameters (orientation, radius, contrast) used to measure a unit’s response as a function of those parameters.

Threshold

The pass line fixed before the test. A threshold chosen after seeing the result is not a threshold.

TransformerLens

A library that loads transformer models with named hook points so activations can be cached and edited; version 4 boots models through TransformerBridge.

Tuning curve

A unit’s response plotted against one stimulus parameter, such as orientation.
