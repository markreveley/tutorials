Module 3 · Language methods on GPT-2 small

Language I: linear probes, with a threshold that failed

A logistic probe on GPT-2 residual activations with a held-out split, a shuffled-label control, and a random-direction control. The pre-registered test fails, and the reason is instructive.

What a probe claims

A linear probe is a classifier fitted on activations to predict a label. If it reaches high accuracy on held-out tokens, the label is linearly readable from the residual stream at that layer. That is the whole claim. It does not say the model uses the direction, that the direction is a single feature, or that anything would change if you removed it; lesson 10 is about those. The probe’s value is that it is cheap and its test is exactly the held-out-accuracy test you already know from the evals course.

The reference script fits logistic regression in numpy (no sklearn in the environment, and none needed) on blocks.6.hook_resid_post, 768 dimensions, standardised, 300 gradient steps with a small L2 penalty. The label is the same sentence-start rule as the neuron in lesson 04. Pre-registered: at layer 6, held-out accuracy at least 10 percentage points above the majority rate and above both controls.

layer 6, label "after_period": train 1664 tokens (0.090 positive), held-out 1536 tokens (0.103 positive); majority-class accuracy 0.897
probe: train accuracy 0.999, held-out accuracy 0.985
shuffled-label control (20 fits): held-out accuracy mean 0.834, max 0.861
random-direction control (20 directions): held-out accuracy mean 0.882, max 0.894
pre-registered test (held-out >= majority + 0.10 and above both controls): FAIL
exploratory, NOT pre-registered: held-out recall on positives 0.930, on negatives 0.991, balanced accuracy 0.961; the largest gain over majority that any probe could reach here is 0.103

Why the test failed

The probe is good: 98.5% held-out, 93% recall on the 10% of tokens that are sentence starts, far above a shuffled-label fit (max 86.1%) and a random direction (max 89.4%). The test failed because the threshold was wrong. With a majority rate of 89.7%, a gain of 10 percentage points requires 99.7% accuracy; the most any probe could gain is 10.3 points. The threshold was written as if the base rate were 50%, which it is not. The author of the threshold (the course) did not compute the base rate on the held-out split before fixing the line.

This is reported as a failure because it is one. The protocol says what to do: the pre-registered result stands, the exploratory numbers are labelled exploratory, and the next pre-registration fixes the threshold properly. Three ways to do that: state the threshold as a fraction of the achievable gain (“recover at least 80% of the gap between majority and 100%”); use balanced accuracy, which has a majority rate of 50% by construction; or pre-register precision and recall at a fixed operating point. Any of the three would have passed here. None of them was written down, so none of them counts.

What the two controls ruled out

The shuffled-label control refits the probe on permuted labels and scores it on the real held-out labels. Its mean of 83.4% is below the majority rate, which tells you something about the probe: with meaningless labels, the fit learns noise and predicts the positive class more often than it should. A probe fit on real labels that scored near 83% would be indistinguishable from this; 98.5% is not.

The random-direction control projects the activations onto a random unit vector, picks the best threshold on the training split, and scores held-out. It reaches 89.4% at best, essentially the majority rate. The point of this control is specific: it rules out the possibility that any direction, with a tuned threshold, reaches the probe’s accuracy because the label is trivially separable (for instance if the activations had a huge norm difference on positives). They do not; the probe found a particular direction.

Why layer 6, and what to do with layers

The sentence-start label is computable from the previous token alone, so a layer-0 probe would likely do about as well, and this is the kind of fact that a layer sweep reveals and a single layer hides. The reference script takes --layer; the practice below asks you to run it at 0 and 11. A probe’s accuracy as a function of layer is a description of where a label is readable, which is a more useful object than a single number, and a sweep is also a place where you can fool yourself by reporting the best layer: pre-register the layer, or report all of them.

The lab

labs/probe.py asks for the fit, the prediction, the majority rate, the two controls, and a verdict that takes the margin as a parameter. The tests use synthetic data with a hidden direction and 15% positives; the shuffled control must fall to about the majority rate, the random-direction control must stay below the probe, and a dataset with no signal must not pass.

In interpretability work

Before fixing a probe threshold, print the majority rate on the held-out split and the maximum achievable gain. Then write the threshold as a fraction of that gain. The failed test above cost nothing but a paragraph; in a paper it would have cost the result.

Pitfall

Reading probe accuracy as evidence that the model “knows” or “uses” the property. Huang et al. put the distinction as observational versus intervention modes: “The observational mode only evaluates whether a concept is encoded, as opposed to used” [Huang et al. 2023]. A probe is observational.

Check your understanding

A probe for “token is inside a quotation” reaches 96% held-out at layer 8 and 95% at layer 0. The author reports layer 8 as where the model represents quotation state. What is wrong?

Reveal the reasoning

The one-point difference between layers is within what a shuffled-label control would need to be compared against, and layer 0 is nearly the embedding, which cannot represent context, so most of the 95% is coming from token identity (quote marks and the words that follow them) rather than quotation state. The right analysis reports all layers, compares each against its controls, and uses a label that cannot be read from the current token alone. If layer 8 is not clearly above layer 0 after that, the claim about representation has not been made.

Practice

Run the probe at layers 0 and 11 and compare with layer 6. Then implement labs/probe.py. Finally, rewrite the lesson’s failed pre-registration with a threshold that respects the base rate and say what it would have concluded.

python labs/reference/probe_run.py --layer 6
python labs/reference/probe_run.py --layer 0
python labs/reference/probe_run.py --layer 11
python -m unittest discover -s labs -p 'test_probe.py' -v
What to look for

If layer 0 is close to layer 6, the label is mostly token-local and the probe says little about layer 6 in particular. A threshold like “balanced accuracy ≥ 0.90 and above both controls” would have passed with 0.961; write that in the protocol notes as the revised, and now pre-registered, test for your own next run.
