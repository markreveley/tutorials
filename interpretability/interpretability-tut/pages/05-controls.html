Module 1 · Evidence that misleads and evidence that counts

Controls: what each one rules out, with worked numbers

Random unit, shuffled labels, baseline explanation, and the held-out split itself. Each closes a different door, and the full table from the authoring run shows them at work.

All eight rules at once

The same screening and scoring procedure, run for every rule the course defines. Nothing was tuned between rules; the pre-registered verdict is the same for all.

        quote     0    121    0.777      0.828   0.069   0.044     0.512      0.016  demonstrated
          the     0    132    0.996      0.997   0.131   0.041     0.335      0.059  demonstrated
   space_word     1   1034    0.651      0.528   0.231   0.042     0.372      0.700  demonstrated

Eight rules, eight neurons found by exhaustive screening, eight held-out scores above 0.5 and above both controls. Before reading that as “GPT-2 small has a neuron for everything,” read the controls, because they are what make the table mean anything.

The random-unit control

Score the same rule against 200 randomly chosen other neurons of the same layer. The 95th percentile (rand95) answers: how well does this rule fit a neuron that was not selected for it? For most rules it is 0.07–0.19, which is the floor set by the rule’s own structure: any rule correlates slightly with many neurons because the tokens it marks are not random tokens. For space_word (a token that starts with a space and is alphabetic, 70% of all tokens) the floor is 0.231, because such a broad rule is weakly correlated with almost everything.

The maximum over the 200 (|rand|max) is the more sobering column. For after_period the single most correlated random neuron reached 0.560, for punct 0.558, for quote 0.512. That is what the tail of 200 draws looks like, and it is why the verdict uses the 95th percentile rather than the maximum: the maximum of a null distribution grows with the number of draws, and a threshold set at the maximum would be a threshold set by how many controls you ran. The statistics course’s multiple-comparisons lesson covers the general case; here the practical rule is to fix the number of control draws in the protocol and compare against a percentile.

The shuffled-label control

Permute the rule’s predictions 500 times and score each against the real neuron. This answers: what does a rule with the right base rate but no content score on this neuron? The 95th percentile is 0.04–0.05 for every rule, which is the sampling floor for 1,536 tokens. If a held-out score were 0.1, this control would tell you it is above chance; it would not tell you it is interesting. The two controls together bracket the score from both sides: the random unit asks whether the rule is special to this neuron; the shuffle asks whether the neuron’s response is special to this rule.

The baseline explanation

A third control is a competing explanation rather than a null. For L2/2928, “after a full stop or newline” scores 0.845. A baseline rule that explains some of the same tokens, say “token is capitalised” (0.727 for its own neuron, L0/1102), can be scored on L2/2928 too. If the baseline scored nearly as high, the specific claim would not have earned its specificity. The reference script does not run this for you; it is the first thing to add in the capstone, and the protocol lab’s judge() accepts any number of named controls for exactly this reason.

The split as a control on yourself

Compare the train r and held-out r columns. For sharp rules the drop is negligible (digit: 0.979 to 0.978). For space_word it is large: 0.651 to 0.528. The screening score is the maximum over 36,864 candidates and includes whatever fit the chosen neuron had to the particular screening chunks; the held-out score is what survives. The drop is a direct measurement of selection bias, and it is largest for the broadest rule because a broad rule has the most ways to fit by accident. Had the threshold been 0.6, space_word would have passed on screening and failed on held-out, which is the correct outcome.

What the table does and does not show

It shows that for eight simple token-level rules, GPT-2 small has at least one MLP neuron whose activation correlates with the rule on held-out prose from this corpus, at a level far above either null. Six of the eight live in layer 0, where neurons are close to token identity, and the deepest, punctuation at layer 9, is the one whose rule needs no context either. The table does not show that these neurons “are for” these properties (lesson 10 is about that), that they do nothing else (a rule explains the variance it explains; 0.845² is 71%), or that the result transfers to text unlike the corpus. Each of those is a further claim with its own test.

In interpretability work

Huang et al. used a random-pairing control for exactly this purpose and found “the random baseline has a F1 score of zero” [Huang et al. 2023] against GPT-4 explanations’ 0.56. The number that matters in any such comparison is the gap, and the gap is only meaningful when the control was run the same way as the claim.

Pitfall

Running controls after seeing the score and stopping when they look low enough. Fix the number of random units and shuffles in the protocol. The reference script uses 200 and 500 and prints both percentiles whatever they are.

Check your understanding

Rule A scores 0.60 held-out with rand95 = 0.12. Rule B scores 0.60 held-out with rand95 = 0.55. Both pass the threshold. Which neuron have you learned more about?

Reveal the reasoning

Rule A’s neuron. The gap between score and random-unit control is what measures the specificity of the rule to the neuron: for B, more than half of the neurons in the layer fit the rule almost as well, so the rule describes something about the layer (or about the rule’s own breadth) rather than about the neuron. B is not a false result, but it is a weak explanation of this particular unit, and the write-up should say so.

Practice

Run the full table. Then pick the row with the largest screening-to-held-out drop and the row with the largest |rand|max, and write one sentence for each explaining which control caught what.

What to look for

The largest drop is space_word, the broadest rule, caught by the held-out split. The largest |rand|max is after_period (0.560): one other layer-2 neuron tracks sentence starts at about two thirds of the chosen neuron’s score, and the 95th percentile, not the maximum, kept the verdict stable.
