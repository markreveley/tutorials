Module 0 · Claims and the protocol

The objects: neurons, directions, heads, features

What the things you make claims about actually are, how each is read out of a forward pass, and why “native neuron” and “learned feature” are different kinds of object.

Neurons

A neuron is one coordinate of an activation vector at one point in the network. In GPT-2 small’s MLP, the hook blocks.L.mlp.hook_post has shape [batch, position, 3072], and neuron j of layer L is column j, a scalar per token. In GoogLeNet, inception3b outputs [batch, 480, 28, 28], and a “neuron” is one of the 480 channels, a scalar per spatial position; the labs read the centre of the map. In both cases the value is after the nonlinearity, so it is zero or positive for ReLU and can be slightly negative for GELU.

The transformer anatomy course derived these shapes from the weights. Here the only thing that matters is that a neuron is a scalar function of the input, which is exactly what makes it testable: predict the scalar, compare.

Directions

A direction is a unit vector in activation space, and projecting the residual stream onto it gives a scalar too. A neuron is the special case where the direction is a coordinate axis. A linear probe (lesson 08) is a direction learned from labels. A sparse-autoencoder feature (lesson 12) is a direction learned without labels. The linear algebra course covered what a projection measures; the point for rigor is that a direction is also a hypothesis, and a learned direction is a hypothesis chosen by a search, so it needs the same held-out test as a neuron found by screening.

Attention heads

A head is not a scalar. It is a pattern, blocks.L.attn.hook_pattern of shape [batch, heads, query, key], with each query row summing to one, plus the information it moves along that pattern. Claims about heads are usually claims about the pattern under a constructed input (“attends to the token after the previous occurrence of the current token”) or about the effect of the moved information on the logits. Lesson 11 turns the first kind into a score; lesson 09 covers the second.

Native neurons versus learned features

Olah et al. define features as directions and say that in the circuits agenda they are “often simply individual neurons” [Zoom In]. The same paper names the problem: “Neural networks often contain ‘polysemantic neurons’ that respond to multiple unrelated inputs,” with the example 4e:55, “a polysemantic neuron which responds to cat faces, fronts of cars, and cat legs,” and offers superposition, a circuit spreading a feature across many neurons, as the reason. Anthropic’s 2023 response was dictionary learning: train a sparse autoencoder to re-express a one-layer model’s 512-neuron MLP in a larger set of sparse directions, and report that “Sparse autoencoders produce interpretable features that are effectively invisible in the neuron basis” [Towards Monosemanticity].

The 2026 essay argues for going back: “This means we can study networks directly, instead of first untangling them,” and revisits the famous example, “The most famous polysemantic neuron is 4e:55 of InceptionV1, which looked like an arbitrary mixture of cats and cars,” concluding “it’s not a cat and car neuron, it’s a V-shape neuron” [Cammarata 2026]. Whether that reading is right is testable in the way this course tests things: does “V-shape” predict 4e:55’s activations on held-out images better than “cat or car” does? Gao’s reply says the old explanation would in fact have failed such a test, since it “would fail to fire on a ton of V shaped objects, and also it would falsely fire on a bunch of round dogs and cars” [Gao 2026]. Notice that both sides agree on the test; the course is about running it.

Reading activations with TransformerLens 4

from transformer_lens import TransformerBridge
model = TransformerBridge.boot_transformers("gpt2")
model.enable_compatibility_mode()          # restores the blocks.L.* hook names
toks = model.to_tokens("The capital of France is")
logits, cache = model.run_with_cache(toks)
cache["blocks.2.mlp.hook_post"].shape      # torch.Size([1, 6, 3072])
cache["blocks.5.attn.hook_pattern"].shape  # torch.Size([1, 12, 6, 6])

Two practical notes from the authoring runs. model.to_tokens truncates to the 1,024-token context window, so the labs tokenise the corpus with model.tokenizer directly and chunk it themselves. And the booted model takes about twenty seconds to load on a CPU, so each reference script loads it once and does all its work in that process.

In interpretability work

Nanda’s guide lists the techniques you should be able to “code it up yourself on a simple model like GPT-2 Small” [Nanda 2025] and recommends TransformerLens for small models. The reason to own the code is rigor: a hook you wrote is a hook whose indexing you can check.

Pitfall

Reading a channel’s activation at the wrong place. GoogLeNet’s inception3b map is 28×28; the centre cell sees a receptive field around the image centre, so a stimulus drawn at the corner tests a different neuron-position pair. The labs draw every stimulus through the centre and read the central 2×2 cells.

Check your understanding

Someone reports that “direction d in layer 6, found by a probe, encodes sentence boundaries with 98.5% accuracy.” Which of the four objects is this, how was it chosen, and what does the choosing imply for the test?

Reveal the reasoning

It is a learned direction, chosen by a supervised fit to labels. The fit searched all 768 dimensions for the combination that best predicts the labels, so accuracy on the fitting data is biased upward and only held-out accuracy counts. The base rate matters too: if 90% of tokens are non-boundaries, 98.5% must be compared with 90%, and with a probe fitted on shuffled labels. Lesson 08 runs exactly this and the pre-registered threshold fails.

Practice

Run the max-activating-examples script on neuron 2928 of layer 2 and read only the first block of output, the top ten. Write one sentence saying what the neuron does. Keep it; lesson 03 shows the rest of the output.

python labs/reference/maxact.py --layer 2 --neuron 2928
What to look for

Most readers write “fires at the start of a new paragraph” or “after a full stop.” Both are reasonable from the top ten. The quantile bands further down show how far each generalises.
