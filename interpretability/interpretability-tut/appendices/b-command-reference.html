Appendix B

Command reference

Every command on these pages, what it runs, and roughly how long it takes on a four-core CPU. Outputs are in the transcript.

Environment

The labs need torch (CPU), torchvision, transformers, transformer_lens 4, and numpy, with GPT-2 small in the Hugging Face cache and torchvision’s GoogLeNet weights in the torch hub cache. Run everything from the course directory with HF_HUB_OFFLINE=1 once the models are cached. python on these pages means that environment’s interpreter; the versions actually used are at the top of the transcript.
