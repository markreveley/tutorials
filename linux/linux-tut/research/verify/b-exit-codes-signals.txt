##### NOTES on the two sweeps above
# 1. Background-job sweep is unreliable: SigIgn 0x6 = SIGINT+SIGQUIT ignored in an async child of non-interactive bash (documented, Bash Manual 3.7.6),
#    but a signal sent immediately after '&' can land BEFORE the child sets that up (QUIT 131 / INT 130 above) or after (QUIT 0 in the first sweep). Race. Not used in the appendix.
# 2. Clean sweep: 'shell=0' for SIGPIPE and SIGXFSZ. Check whether python itself ignores them:
$ python3 -c 'print(open("/proc/self/status").read())' | grep SigIgn
SigIgn:	0000000001001000
#    0x1001000 = bits for signal 13 (SIGPIPE) and signal 25 (SIGXFSZ); bit N-1 stands for signal N: python ignores both, so signalling itself is a no-op. Artefact of the test program, not of the shell.
#    Shell-side values for those two, observed another way:
