Transformer Anatomy

Residual stream, attention heads, MLP layers, gated MLPs, and tokenization, built up to a GPT-2 forward pass from raw weights that matches the reference.

The readiness test

Implement a GPT-2 forward pass from raw weights, match the reference logits, then re-derive the same activations with TransformerLens and nnsight.

What you will be able to do

  • Say what a token is, why " the" and "the" differ, and what a token boundary does to a claim about a model.
  • Trace one residual-stream vector from embedding to logits and name every write to it.
  • Compute one attention head by hand on three tokens, and describe a real head as a QK circuit and an OV circuit.
  • Locate a neuron in an MLP, compute GELU and SwiGLU on a pencil example, and say which models use which.
  • Write a 150-line GPT-2 forward pass that matches Hugging Face to about 1e-4 and derive its 124,439,808 parameters from the config.
  • Find the same activation under its Hugging Face, TransformerLens 4, and nnsight names, with a verified table.

How to work through it

This course assumes the Python for Model Internals and Linear Algebra for Interpretability courses: you can load GPT-2, index tensors, and read a matrix product. Each lesson has a worked mechanism, an implication for interpretability work, a pitfall, a check with a revealable explanation, and practice. Pencil examples use numbers you can recompute by hand; terminal blocks show real output from the commands above them.

Read the lessons in order the first time. The three labs under labs/ are stubs with tests: tokenization drills (lesson 01), one attention head (lessons 05–06), and the capstone forward pass (lesson 10). The readiness review is a rubric for the test above.

Practice locally

Open this file directly in a browser; reading needs no server or packages. For the terminal work, use a Python environment with torch, transformers, transformer_lens (4.x), and nnsight installed and GPT-2 small in the Hugging Face cache, then run from this course directory:

python labs/anatomy.py --help
python labs/anatomy.py tokens "The cat sat on the mat"
python -m unittest discover -s labs -p 'test_*.py' -v

The shapes and notation appendix lists every tensor; the command reference lists every inspection command with the lesson it belongs to.

Part of the path to interpretability

This is course 3 of 4 on the path from evals to mechanistic interpretability. It follows Python for Model Internals and Linear Algebra for Interpretability, and leads into Interpretability Methods and Rigor. The rigor habits come from Statistics for Evals and Understanding LLM Evals: state what a claim predicts before looking.

Sources and scope

Architectural facts are supported by the annotated bibliography or by the installed model's config and weights, with the command recorded. The code is small enough to read in full. It teaches anatomy on GPT-2 small; it is not a general or fast implementation.
