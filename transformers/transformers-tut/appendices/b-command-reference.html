Appendix B

Command reference

Every sub-command of labs/anatomy.py, the lesson it belongs to, and the test commands. All run from the course directory.

Environment

A Python environment with torch, transformers (5.x), transformer_lens (4.x), and nnsight, with gpt2 in the Hugging Face cache. The authoring versions are recorded at the top of the transcript. Set HF_HUB_OFFLINE=1 to avoid network lookups; the tool sets it by default.

Transformer Anatomy: small inspection commands for GPT-2 small.

Every lesson's terminal output comes from this file. Run from the course directory:

    python labs/anatomy.py tokens "The cat sat on the mat"
    python labs/anatomy.py --help

Commands that need a model load `gpt2` from the local Hugging Face cache. Set
HF_HUB_OFFLINE=1 to avoid network lookups. `names` also needs transformer_lens
and nnsight; everything else needs only torch and transformers.

positional arguments:
  {tokens,bpe-demo,embed,stream,layernorm-demo,attention-demo,heads,mlp-demo,swiglu-demo,logit-lens,softmax-demo,config,shapes,generate,names,compare}
    tokens              show GPT-2 token ids and pieces
    bpe-demo            train a toy byte-pair encoder step by step
    embed               token and position embeddings for a prompt
    stream              residual stream norms layer by layer
    layernorm-demo      LayerNorm, RMSNorm, and folding on a 4-vector
    attention-demo      one head on a 3-token pencil example
    heads               one real GPT-2 attention pattern and its QK/OV
                        circuits
    mlp-demo            MLP activations and GELU values
    swiglu-demo         SwiGLU on a 2-vector
    logit-lens          unembed every block's residual stream
    softmax-demo        softmax and temperature on three logits
    config              derive the parameter count from the config
    shapes              every tensor in the state dict with its shape
    generate            greedy and sampled generation, with and without a KV
                        cache
    names               verify activation names across HF, TransformerLens 4,
                        and nnsight
    compare             compare labs/gpt2_from_scratch.py with the reference
                        model

options:
  -h, --help            show this help message and exit
