Sources and provenance

Annotated bibliography

Primary papers, library documentation, and installed model code, with the verified scope of each source.

These sources were opened and checked during authoring on 2026-10-20. The notes identify the scope verified; they do not claim that an entire source was independently reproduced. Facts about the installed GPT-2 checkpoint were verified against its config and state dict, with the commands recorded in the transcript.

Vaswani 2017

Vaswani et al. (2017), Attention Is All You Need, arXiv:1706.03762

Verified from the PDF: Attention(Q,K,V) = softmax(QK^T/sqrt(d_k))V (eq. 1); the 1/sqrt(d_k) scale is motivated by large dot products pushing softmax into small-gradient regions; MultiHead = Concat(head_1..head_h)W^O with head_i = Attention(QW_i^Q, KW_i^K, VW_i^V); base model d_model=512, h=8, d_k=d_v=64, d_ff=2048; FFN(x)=max(0, xW_1+b_1)W_2+b_2; masking sets illegal connections to -inf before the softmax; the embedding matrix is shared with the pre-softmax linear transformation.

Radford 2019

Radford, Wu, Child, Luan, Amodei & Sutskever (2019), Language Models are Unsupervised Multitask Learners, §2.3

Verified from the PDF: layer normalization was moved to the input of each sub-block and an additional layer normalization was added after the final self-attention block; residual-layer weights are scaled at initialization by 1/sqrt(N); the vocabulary is 50,257; context size 1024; Table 2 lists the smallest model as 117M parameters, 12 layers, d_model 768. The installed 124M checkpoint is the model the model card calls 124M; this course reports the number its weights support.

GPT-2 model card

openai/gpt-2 repository, model_card.md

Verified: the released sizes are described as 124 million, 355 million, 774 million, and 1.5 billion parameters; training data is WebText. The card does not describe the architecture.

Elhage 2021

Elhage, Nanda, Olsson et al. (2021), A Mathematical Framework for Transformer Circuits

Verified from the fetched page: attention and MLP layers read from and write to the residual stream; the stream has no privileged basis; virtual weights are products of one layer's output weights with a later layer's input weights; a head has a QK circuit computing the attention pattern and an OV circuit computing how an attended token affects the output, as the low-rank matrices W_Q^T W_K and W_O W_V; per-head output h(x)_i = W_O sum_j A_ij v_j; heads are independent and additive. The course's matrix orientation (row vectors, W_Q W_K^T) is stated where it differs.

Shazeer 2020

Shazeer (2020), GLU Variants Improve Transformer, arXiv:2002.05202

Verified from the PDF: Swish_beta(x) = x sigma(beta x); SwiGLU(x,W,V,b,c,beta) = Swish_beta(xW+b) ⊗ (xV+c); FFN_SwiGLU(x,W,V,W_2) = (Swish_1(xW) ⊗ xV)W_2 with biases omitted; the GLU variants have three weight matrices, and d_ff is reduced by 2/3 to keep parameter count constant; GEGLU and SwiGLU gave the best pre-training perplexities in its T5 experiments. No numbers from its tables are reproduced here.

Touvron 2023

Touvron et al. (2023), LLaMA: Open and Efficient Foundation Language Models, §2.2

Verified from the PDF: pre-normalization of each sub-layer input with RMSNorm; SwiGLU replacing ReLU with hidden dimension 2/3·4d; rotary positional embeddings at each layer in place of absolute positional embeddings; Table 2 lists 6.7B (dim 4096, 32 heads, 32 layers) up to 65.2B (dim 8192, 64 heads, 80 layers).

Qwen3 report

Yang et al. (2025), Qwen3 Technical Report, arXiv:2505.09388, §2 and Table 1

Verified from the HTML: dense models use grouped-query attention, SwiGLU, rotary positional embeddings, and RMSNorm with pre-normalization; QKV bias was removed and QK-Norm added; Table 1 lists Qwen3-0.6B with 28 layers, 16 query and 8 key/value heads, tied embeddings, and 32K context; sizes range from 0.6B to 235B, dense and mixture-of-experts.

TransformerLens 4 migration

TransformerLens documentation: Migrating to TransformerLens 4.0

Verified: 4.0 removes the legacy Hooked* model stack; HookedTransformer maps to TransformerBridge.boot_transformers(name) plus enable_compatibility_mode(); compatibility mode reproduces HookedTransformer's default weight processing (LayerNorm folding, center_writing_weights, center_unembed); omitting it works with raw Hugging Face weights.

TransformerLens compatibility mode

TransformerLens documentation: TransformerBridge Compatibility Mode

Verified: the signature of enable_compatibility_mode with fold_ln, center_writing_weights, center_unembed, fold_value_biases defaulting to True; no_processing=True keeps raw weights; folding means logits will not match Hugging Face; center_unembed makes logits mean-zero without changing argmax; legacy hook names resolve on every bridge; the call mutates weights in place and should not be repeated.

TransformerLens hooks

TransformerLens documentation: The Hook System

Verified: run_with_cache returns (logits, cache); cache keys such as blocks.0.attn.hook_q, blocks.5.hook_resid_post, blocks.5.attn.hook_z, ln_final.hook_normalized; add_hook on a hook point. The full key list in lesson 13 was produced by running the installed package, not copied from documentation.

nnsight quickstart

nnsight documentation: Quickstart

Verified: TransformersModel('openai-community/gpt2', task='text-generation', device_map=..., dispatch=True); task should be passed explicitly when offline; model.trace(prompt) runs a forward pass exposing internals; values must be .save()d to survive the block.

nnsight: getting activations

nnsight documentation: Getting Activations

Verified: .output reads a module's return value and .input its first positional argument; modules must be requested in the order they run within one invoke, otherwise OutOfOrderError is raised.

Su 2021

Su et al. (2021), RoFormer: Enhanced Transformer with Rotary Position Embedding, arXiv:2104.09864

Verified from the abstract: RoPE encodes absolute position with a rotation matrix and makes self-attention depend on relative position. The pairing and rotation formula used in lesson 14 was read from the installed Hugging Face Llama code.

Zhang & Sennrich 2019

Zhang & Sennrich (2019), Root Mean Square Layer Normalization, arXiv:1910.07467

Verified from the abstract: RMSNorm drops LayerNorm's re-centering and normalizes by the root mean square, keeping re-scaling invariance. The formula in lesson 14 was read from the installed Hugging Face Llama code.

Ainslie 2023

Ainslie et al. (2023), GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints, arXiv:2305.13245

Verified from the abstract: grouped-query attention uses an intermediate number of key/value heads, more than one but fewer than the number of query heads, between multi-query and multi-head attention.

Sennrich 2015

Sennrich, Haddow & Birch (2015), Neural Machine Translation of Rare Words with Subword Units, arXiv:1508.07909

Verified from the abstract: rare and unseen words are encoded as sequences of subword units, with byte pair encoding among the segmentation methods compared. The toy trainer in lesson 01 is original.

Hendrycks & Gimpel 2016

Hendrycks & Gimpel (2016), Gaussian Error Linear Units (GELUs), arXiv:1606.08415

Verified from the PDF: GELU(x) = x Phi(x) = x·½[1+erf(x/sqrt 2)], with the approximations 0.5x(1+tanh[sqrt(2/pi)(x+0.044715x^3)]) and x sigma(1.702x).

nostalgebraist 2020

nostalgebraist (2020), interpreting GPT: the logit lens

Verified: applying the model's final projection to vocabulary space at intermediate layers gives distributions that converge toward the final output, often well before the last layer. The course's logit-lens output is computed locally.

transformers GPT-2 code

Hugging Face transformers 5.20.2, models/gpt2/modeling_gpt2.py and activations.py (installed copy read)

Verified in the installed package: Conv1D computes x @ weight + bias with weight shape (in, out); the block applies ln_1 before attention and ln_2 before the MLP, adding each output to the residual; scaling is head_dim ** -0.5; NewGELUActivation is the tanh formula; the config says activation_function gelu_new, layer_norm_epsilon 1e-5, tie_word_embeddings true.

transformers Llama and Qwen3 code

Hugging Face transformers 5.20.2, models/llama/modeling_llama.py and models/qwen3/modeling_qwen3.py (installed copies read)

Verified in the installed package: LlamaMLP computes down_proj(act_fn(gate_proj(x)) * up_proj(x)) with hidden_act silu; LlamaRMSNorm multiplies x by rsqrt(mean(x^2)+eps) and then by a weight; input_layernorm precedes attention and post_attention_layernorm precedes the MLP; rotate_half pairs the first and second halves of head dims and q_embed = q*cos + rotate_half(q)*sin; repeat_kv expands num_key_value_heads to num_attention_heads; Qwen3 adds q_norm and k_norm over head_dim.

See source-checking notes and the machine-readable source record. No benchmark results or model-quality claims are asserted.
