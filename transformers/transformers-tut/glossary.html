Reference

Glossary

Definitions in the language of model internals. Linked terms in lessons also show keyboard-accessible tooltips.

Activation cache

A dictionary of named activations captured during one forward pass; TransformerLens's run_with_cache returns one.

Attention head

One unit of attention: its own query, key, value, and output maps of width d_head. GPT-2 small has 12 per layer.

Attention pattern

The (query position, key position) matrix of softmax weights; each row sums to 1. It says where a head reads, not what it does with what it reads.

Attention score

The scaled dot product q·k / sqrt(d_head) before the softmax.

Block

One attention layer followed by one MLP layer, each wrapped in a layer norm and a residual addition. GPT-2 small has 12.

Byte-pair encoding

A tokenizer-building procedure that repeatedly merges the most frequent adjacent pair of symbols in a corpus; the merge list is then applied in order to new text.

Causal mask

Setting scores for key positions after the query position to minus infinity, so a token cannot attend to the future.

Context window

The maximum sequence length the model was built for: 1024 positions in GPT-2, fixed by the size of wpe.

d_head

The width of one head's query, key, and value vectors: d_model / n_head = 64 in GPT-2 small.

d_mlp

The hidden width of the MLP, 3072 = 4 × d_model in GPT-2 small. Hugging Face calls it n_inner or intermediate_size.

d_model

The width of the residual stream, 768 in GPT-2 small. Also called hidden size or n_embd.

Embedding

The lookup that maps a token id to a d_model-dimensional vector: row id of the matrix wte.

End-of-text token

GPT-2's token 50256, <|endoftext|>. TransformerLens prepends it as a beginning-of-sequence token by default; Hugging Face and nnsight do not.

Forward pass

Running the model once from token ids to logits with no gradient computation.

Gating

Multiplying one branch of a computation elementwise by another, so one branch decides how much of the other passes.

GELU

The activation x·Φ(x), with Φ the standard normal CDF. GPT-2 uses the tanh approximation called gelu_new.

Grouped-query attention

Several query heads share one key/value head, shrinking the KV cache. Qwen3-0.6B has 16 query heads and 8 key/value heads.

hidden_states

Hugging Face's tuple of residual-stream snapshots: entry 0 after embedding, entry i after block i−1, and the last entry after the final layer norm.

Hook

A function attached to a point in the forward pass that sees (and may replace) the activation there.

Key

The vector a position offers to be matched against queries; k = x W_K.

KV cache

The keys and values of every earlier position, stored so generating the next token recomputes only the new position.

Layer norm

Normalise a vector to mean 0 and variance 1 across d_model, then scale by a learned weight and shift by a learned bias.

Layer-norm folding

Multiplying the layer norm's weight and bias into the next linear layer so the normalisation step has no learned parameters. The function is unchanged.

Logit lens

Applying ln_f and the unembedding to the residual stream after an earlier block, to see what the model would predict if it stopped there.

Logits

The unnormalised scores over the vocabulary at each position, shape (batch, seq, d_vocab). Softmax turns a row into next-token probabilities.

MLP

The block's position-wise two-layer network: up-project to d_mlp, apply a nonlinearity, down-project to d_model.

Multi-head attention

Several heads run in parallel on the same input; their outputs are summed (equivalently, concatenated and multiplied by one output matrix).

Neuron

One hidden unit of an MLP: a column of the up-projection (its input direction), a scalar activation, and a row of the down-projection (its output direction).

OV circuit

The matrix W_V W_O (d_model by d_model, rank at most d_head) that maps an attended residual vector to what the head writes. It determines what attention moves.

Parameter count

The number of learned scalars; 124,439,808 for GPT-2 small, derived from the config in lesson 11.

Positional embedding

A learned vector added to each position's token embedding so the model can tell positions apart. GPT-2 learns one per position (wpe); Llama-style models use rotations instead.

Pre-LN

Placing the layer norm on the input of each sub-block, before attention and before the MLP, so the residual stream itself is never normalised until ln_f.

Privileged basis

A coordinate system that the computation singles out. The residual stream has none (any rotation works if all weights rotate too); MLP neurons do, because the nonlinearity acts per coordinate.

QK circuit

The matrix W_Q W_K^T (d_model by d_model, rank at most d_head) that scores a query residual against a key residual. It determines the attention pattern.

Query

The vector a position uses to ask what to attend to; q = x W_Q.

Residual stream

The running (seq, d_model) vector per token that every block reads from and adds to. The final stream is the embedding plus every attention and MLP output.

RMSNorm

Layer norm without the mean subtraction and without the bias: divide by the root mean square, then scale.

Rotary embedding

RoPE: rotating pairs of query and key dimensions by an angle proportional to position, so dot products depend on relative position. No position vector is added to the stream.

Sequence position

The index of a token within the input, the middle axis of a (batch, seq, d_model) tensor.

Softmax

Exponentiate every entry and divide by their sum, giving positive weights that add to 1. Invariant to adding a constant to all entries.

State dict

PyTorch's mapping from parameter names to tensors; the raw weights the capstone loads.

SwiGLU

A gated MLP: (Swish(xW) ⊙ xV) W_2, with three matrices instead of two. Used by Llama and Qwen3.

Temperature

A divisor applied to logits before sampling. Below 1 sharpens the distribution; above 1 flattens it; greedy decoding is the limit of 0.

Tied embeddings

Using the same matrix for embedding and unembedding. GPT-2's lm_head.weight is literally transformer.wte.weight.

Token

The unit the model reads: an integer id standing for a string piece chosen by the tokenizer. GPT-2 has 50,257 of them.

Token boundary

The place where one token ends and the next begins. A claim about "the word cat" is really a claim about whichever tokens cover it.

Tokenizer

The fixed procedure that turns text into token ids and back. It is not part of the neural network and is not learned with it.

Unembedding

The final linear map from the residual stream to one logit per vocabulary entry. In GPT-2 it is the transpose of the embedding matrix.

Value

The vector a position contributes when attended to; v = x W_V.

Virtual weights

The product of one layer's output weights with a later layer's input weights: the effective linear map between them through the residual stream.

Vocabulary

The set of all token strings, indexed by id. Its size is the last dimension of the logits.
