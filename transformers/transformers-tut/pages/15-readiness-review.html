Module 4 · Tooling and variants

Readiness review

The test is concrete. This page is the rubric for it, a checklist of what you should now be able to say without looking, and the handoff to the interpretability course.

The test

Implement a GPT-2 forward pass from raw weights, match the reference logits, then re-derive the same activations with TransformerLens or nnsight. In this course that is three commands:

python -m unittest discover -s labs -p 'test_*.py' -v
python labs/anatomy.py compare --tools
python labs/anatomy.py names

With the stubs unimplemented, the test suite reports errors (the transcript records that state); with a correct implementation all 24 tests pass, and the comparison prints every max-difference at or below 1e-4 against Hugging Face, TransformerLens in no-processing mode, and nnsight.

Ten things to say without looking

  1. The signature: ids (b, s) → logits (b, s, 50257); the stream in between is (b, s, 768).
  2. The first residual vector is wte[id] + wpe[pos]; nothing else happens before block 0.
  3. The stream is a sum of 1 + 24 writes; the norms do not add; position 0 is an outlier in this checkpoint.
  4. Pre-LN: ln_1 before attention, ln_2 before the MLP, ln_f before the unembedding; the stream is never normalised in place; LN is scale-invariant and deletes the all-ones direction.
  5. Attention: scores q·k/√64, mask with −∞, softmax rows sum to 1, output is a convex mix of values.
  6. Two circuits: W_Q W_Kᵀ decides where, W_V W_O decides what, each rank ≤ 64 in a 768-space.
  7. A neuron is a column of W_in, a scalar after GELU, and a row of W_out; the hidden basis is privileged, the stream's is not.
  8. SwiGLU is (SiLU(xW) ⊙ xV)W₂; used by Llama and Qwen3; a neuron then has two input directions.
  9. Logits are ln_f(stream) · wteᵀ; the logit lens applies the same ending earlier; softmax ignores a constant shift.
  10. TransformerLens 4 loads with boot_transformers + enable_compatibility_mode; default mode folds and centres; no_processing matches Hugging Face; nnsight needs save(), execution order, and a file.

What comes next

The interpretability course uses everything here. Its first language-model replication reads a neuron under blocks.N.mlp.hook_post and an attention head under blocks.N.attn.hook_pattern, and its rule, from the evals course and the statistics course, is that the prediction test is written before the look: say what the activation will do on held-out data, say what control would also pass if the explanation were empty, then run. The anatomy on these pages is what makes those sentences precise: which tensor, which position, which token id, which library, which processing mode.

For tutors

labs/ASSESSMENTS.md describes held-out variant families for each lab (different prompts, different layers, perturbed hand examples, and modified-architecture forward passes) without publishing them, following the repository's assessment contract. A learner who passes the published tests should be given one variant from each family.

In interpretability work

The readiness test is a test of your ability to be wrong in a detectable way. A forward pass that matches to 1e-4 is one you can modify for an experiment and still trust; an activation you can locate in three libraries is one whose provenance you can defend in a write-up. That is the whole purpose of anatomy.

Pitfall

Declaring readiness after the tests pass once. Run the comparison on a prompt you chose, with a different length, and on a batch of two if you extended the implementation that far. The tests are a floor.

Check your understanding

Your implementation passes every test. A reviewer asks for one piece of evidence that it is correct rather than fitted to the test prompt. What do you show?

Reveal the reasoning

The compare command on a prompt the tests never used, with its max-differences at the same 1e-4 scale and argmax agreement, plus the names table at a layer other than 5 showing your cache agrees with both libraries. Because the implementation has no prompt-specific code paths and the comparison is against an independent implementation, agreement on a fresh prompt is evidence about the code rather than about the prompt.

Practice

Run the comparison on this longer prompt (eighteen tokens) with your implementation. Record the maximum differences.

python labs/anatomy.py compare --tools "Mechanistic interpretability asks what a model computes, not only what it outputs."
What to look for

With the reference implementation this prompt gives a logit discrepancy of about 9e-5 against a largest logit near 197, and residual discrepancies around 1e-4; your numbers should be of the same order. If they are larger by a factor of ten or more, something is systematically off even though the short prompt passed.
