Module 0 · The object of study

The model is a function from token ids to logits

Before any mechanism, fix the signature: integers in, one score per vocabulary entry out, and a residual stream in between that every part reads and writes.

One function, one intermediate object

Strip away the tooling and GPT-2 small is a pure function. Its input is a tensor of token ids with shape (batch, seq). Its output is a tensor of logits with shape (batch, seq, 50257): at every position, one unnormalised score for each of the 50,257 entries in the vocabulary. Nothing about the model is stateful during a forward pass; the same ids give the same logits every time.

Between input and output there is one object worth naming now, because the rest of the course is about it. The residual stream is a vector of width 768 per token, shape (batch, seq, 768). It is created by the embedding, then twelve blocks each add something to it, then a final normalisation and one matrix multiply turn it into logits. Every attention head and every MLP neuron is a function that reads the stream and writes a vector back into it. Elhage et al. describe the layers as communicating by reading from and writing to subspaces of this one channel [Elhage 2021]; this course takes that description as its map.

token ids (batch, seq) │ wte[id] + wpe[pos] ▼ residual stream (batch, seq, 768) ──► +attention ──► +MLP ──► … ×12 blocks │ ln_f, then × W_U ▼ logits (batch, seq, 50257)

What you will build

The readiness test for this course is concrete: implement the forward pass from the raw weights in Hugging Face's state_dict, match the reference logits to a stated tolerance, and then re-derive the same intermediate activations with TransformerLens 4 and nnsight. The capstone in lesson 10 is about 90 lines of plain PyTorch; the reference solution used to produce this course's transcripts matches Hugging Face's logits to within 3.05e-05 on the running example, where the largest logit is about 134.

Along the way, every piece is computed twice: once on a pencil example small enough to check by hand, and once on the real model with a command whose output is shown unedited. The running prompt is "The cat sat on the mat", six tokens, chosen because it is short enough to print a whole attention pattern.

The numbers that fix the scale

Four integers set every shape in GPT-2 small, and they come from the installed model's config rather than from memory [Radford 2019]:

NameValueWhat it sizes
d_vocab50,257rows of the embedding; last axis of the logits
n_ctx1,024rows of the positional embedding; longest input
d_model768width of the residual stream
n_layer, n_head12, 12blocks; heads per block, each of width 768/12 = 64

The MLP hidden width is 4 × 768 = 3,072. From these you can derive the parameter count, 124,439,808, by hand; lesson 11 does it line by line and checks it against the weights.

How this course treats evidence

Three kinds of statement appear on these pages and they are held to different standards. Mechanism (what a dot product is, how softmax works) is explained in original words and needs no citation. Architectural facts about a particular model (where GPT-2 puts its layer norms, which models use SwiGLU, how many heads Qwen3-0.6B has) are tied to a fetched source or to the installed model's own config and weights, and the bibliography says which. Numbers in terminal blocks were produced by running the command shown; the transcript under research/verify/ records the interpreter, package versions, and every output.

The authoring environment was CPU-only PyTorch with transformers 5.20.2, transformer_lens 4.2.0, and nnsight 0.8.1. Two toolchain facts matter immediately: TransformerLens 4 removed HookedTransformer, so models are loaded with TransformerBridge.boot_transformers("gpt2") followed by enable_compatibility_mode(); and an nnsight trace block must run from a file or notebook cell, not from a piped stdin session. Lesson 13 covers both.

In interpretability work

Every claim you will later make about a head or a neuron is a claim about one of the tensors in the diagram above, at a named position, for a named token. Being able to say which tensor, which position, and which token id, before you look at any plot, is the skill this course trains.

Pitfall

Treating the model as a text-to-text system. The model never sees text. It sees integers chosen by a separate, fixed tokenizer, and it emits scores, not words. Many wrong intuitions about "the word cat" dissolve once you ask which token ids actually arrived.

A first look at the tool

All terminal work uses one script with sub-commands. The config command prints the integers above and derives the parameter count:

python labs/anatomy.py config
n_layer=12 n_head=12 n_embd=768 n_positions=1024 vocab_size=50257 activation=gelu_new layer_norm_epsilon=1e-05 tie_word_embeddings=True
wte = 50257 x 768 = 38,597,376
wpe = 1024 x 768 = 786,432
per block: ln_1 1,536 + attn (c_attn 1,771,776 + c_proj 590,592) + ln_2 1,536 + mlp (c_fc 2,362,368 + c_proj 2,360,064) = 7,087,872
12 blocks = 85,054,464; ln_f = 1,536
derived total = 124,439,808
sum of parameter.numel() over the model = 124,439,808  (lm_head shares wte, so it is not counted twice)
match: True

Three of those config values are worth noticing now: activation=gelu_new (lesson 07), layer_norm_epsilon=1e-05 (lesson 04), and tie_word_embeddings=True (lesson 09). Each is a fact about this checkpoint that a from-scratch implementation has to get right.

Check your understanding

A colleague says "the model represents the concept of cats at layer 6." Translate that into a statement about a tensor: which tensor, what shape, and what else must be specified before it can be tested?

Reveal the reasoning

The residual stream after block 6 (or into it; say which), shape (batch, seq, 768), at one or more named positions. You also need the token ids that arrived (tokenization is not fixed by the word "cats"), a direction or subspace of the 768-dimensional space that is supposed to carry the concept, and a prediction about what reading that direction at those positions should give on inputs you have not yet looked at. Without the positions and the direction, the claim has no tensor to be checked against.

Practice

Run the help command and read the list of sub-commands; each belongs to one lesson. Then run config and recompute one line by hand: the attention c_attn count 768 × 2304 + 2304.

python labs/anatomy.py --help
python labs/anatomy.py config
What to look for

768 × 2304 = 1,769,472, plus a bias of 2,304 gives 1,771,776, which is the printed c_attn figure. The 2304 is 3 × 768: queries, keys, and values for all twelve heads in one matrix. The help text lists sixteen commands; the only ones needing TransformerLens and nnsight are names and compare --tools.
