Reference

Glossary

Definitions in the language of model-internals work. Linked terms in lessons also show keyboard-accessible tooltips.

Activation cache

A dictionary from a name such as blocks.5.hook_resid_post to the tensor captured at that point of the forward pass.

Aliasing

Two or more names referring to the same object, so a mutation through one is visible through all.

Attention mask

A (batch, seq) tensor of ones and zeros marking real tokens versus padding when prompts of different lengths share a batch.

Autograd

PyTorch's mechanism for recording operations on tensors that require gradients and computing derivatives with backward().

Axis

One dimension of an array, numbered from 0. Negative numbers count from the end; axis -1 is the last.

Binding

Associating a name with an object. Assignment rebinds a name; it never copies the object.

Broadcasting

The rule that lets arrays of different shapes combine: align shapes at the right; each pair of sizes must be equal or one of them 1.

Contiguous

Laid out in memory in row-major order with no gaps. Transposes and some slices are not; .view needs contiguity, .reshape copies when needed.

Dataclass

A class whose __init__, __repr__ and __eq__ are generated from its annotated fields by the @dataclass decorator.

detach

Return a tensor sharing data with the original but cut off from the autograd graph.

Device

Where a tensor lives: cpu, or an accelerator such as cuda. Operations need their operands on the same device.

dtype

The element type of an array or tensor, such as float32, float16 or int64. It decides precision, memory, and which operations are allowed together.

einsum

Einstein-summation notation: a string names each operand's axes with letters; letters missing from the output are summed over.

Eval pipeline

The three practice functions in labs/eval_pipeline.py: score a prediction, load validated cases, and summarise a run without losing failures.

Exception

Python's error channel: an object raised to unwind the stack until a matching except clause catches it.

Forward hook

A function registered on a module that runs after its forward() with (module, args, output). It returns a handle you must remove.

Generator

A function with yield, or an expression in parentheses, that produces values on demand and keeps nothing it has already produced.

Gradient

For a scalar loss, the vector of partial derivatives with respect to each parameter: how much the loss changes per small change in that parameter.

hidden_states

The transformers tuple returned by output_hidden_states=True: the embedding output plus one tensor per layer; 13 for GPT-2 small, and the last has the final LayerNorm applied.

In-place operation

A PyTorch method with a trailing underscore, such as add_, that modifies its tensor's storage instead of returning a new one.

JSONL

A text file with one JSON value per line. Blank lines are skipped by convention but still count as physical lines.

keepdims

A reduction option that keeps the reduced axis with size 1 so the result still broadcasts against the input.

Logits

Unnormalised scores for each vocabulary item at each position, shape (batch, seq, vocab). A softmax over the last axis turns them into probabilities.

Mutability

Whether an object's value can change in place. Lists, dicts, sets and tensors are mutable; ints, strings and tuples are not.

nn.Module

PyTorch's base class for models and layers: a tree of submodules with named parameters and a forward method.

no_grad

A context manager under which operations are not recorded by autograd. Use it for every forward pass whose gradients you will not need.

Object

Everything a Python program manipulates: it has an identity (address), a type, and a value. Names refer to objects; they do not contain them.

Parameter

A tensor registered on a module so that it appears in parameters() and state_dict() and is trained.

Reduction

An operation such as sum, mean or max that removes one or more axes by combining values along them.

requires_grad

A tensor flag that asks autograd to record operations on it. Model parameters have it on; cached activations should not.

Residual stream

The (batch, seq, d_model) tensor that each transformer block reads from and adds to. GPT-2 small's d_model is 768.

Run manifest

A small JSON record of what produced an artifact: model, prompts, seed, versions, and each tensor's shape, dtype and checksum.

safetensors

A file format for tensors that stores raw bytes with a JSON header, loads without executing code, and is the Hugging Face default.

Seed

The starting state of a pseudo-random generator. The same seed and code give the same draws on the same software and hardware.

Shallow copy

A new container whose elements are the same objects as the original's. Nested containers remain shared.

Shape

The tuple of sizes along each axis of an array or tensor. (2, 5, 768) means 2 items, 5 positions, 768 features.

Spec first

Writing the test that states the required behaviour before the implementation, then making it pass.

state_dict

A dictionary from parameter and buffer names to tensors: the whole learned state of a module, used to save and load weights.

Tensor

PyTorch's n-dimensional array, with a dtype, a device, and optional autograd tracking.

Tokenizer

Maps text to a sequence of integer token ids and back. GPT-2's byte-pair tokenizer attaches the leading space to the following word.

Type hint

An annotation such as list[str] that documents an intended type. Python does not enforce it at run time.

View

A tensor or array that shares storage with another. Writing through a view changes the base.
