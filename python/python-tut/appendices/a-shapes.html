The rules

Indexing: each integer index removes an axis; each slice keeps it; None adds one; ... stands for all leading axes. Basic slices are views; boolean and list indexing copy.

Broadcasting: align shapes at the right, pad the shorter with ones on the left, and at each position the sizes must be equal or one of them 1; the result takes the larger. In place, the result may not be larger than the in-place operand. [NumPy: broadcasting] [PyTorch: broadcasting]

Reductions: the named axis disappears; keepdims=True keeps it as size 1; argmax returns indices with the same shape rule.

einsum: one letter per axis per operand; a letter missing from the output is summed; a letter repeated in one operand takes the diagonal; always write the ->. [NumPy: einsum]

Views: view, transpose, permute, squeeze, slices and from_numpy share storage; reshape may or may not; clone and copy do not. [PyTorch: views]

The asserts to copy

assert acts.shape == (batch, seq, 768), acts.shape
assert acts.dtype == torch.float32, acts.dtype
assert not acts.requires_grad
assert torch.isfinite(acts).all()
assert pattern.shape[-2:] == (seq, seq) and torch.allclose(pattern.sum(-1), torch.ones_like(pattern[..., 0]))

Write the shape comment next to every tensor assignment. A comment that says # (batch, seq, 768) is cheaper than the hour you spend when it is not there.
