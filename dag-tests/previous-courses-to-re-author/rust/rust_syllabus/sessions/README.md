# Session evidence

[Progress](../curriculum/progress.json) records actual attempts. Inspect those records before drawing conclusions about progress.

Use the start command described in the root README to create sessions/M1-NN/attempt-01.md. A second attempt becomes attempt-02.md without rewriting the earlier record.

For the M1-01 agent-led pilot, the attempt is agent-maintained: the learner responds in conversation, and the agent preserves actual answers/results and the saved step without a separate lab report. attempt-02.md is the active continuation of the learner-protected attempt-01.md, not a claim that an independent check was retried.

Other lessons retain their document-led workflow. Instructions live in the lesson; the attempt holds answers/results and a Handover naming the section to resume.

Each record preserves the learner's actual prediction, observed evidence, assistance level, independent assessment, remaining gaps, and next step. The template is in templates/session.md.

Do not store Bandit passwords, cloud credentials, private machine addresses, raw environment dumps, or customer data.
