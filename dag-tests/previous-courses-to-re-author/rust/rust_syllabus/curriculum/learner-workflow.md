# Learner workflow

## Lesson 1 pilot

Work in this conversation. The agent tells you what you are learning and why, then gives one question or action at a time. Use Terminal for the experiment and paste the requested result here.

You do not need to keep separate lesson, preflight, lab-report and attempt files open. The agent follows the authored lesson and records your actual responses, assistance and stopping point. You can inspect those files, but maintaining them is not homework.

To resume, say “resume Lesson 1.” The agent reads the saved step and uses your earlier work without restarting it. Setup appears only when needed. A fresh independent check still requires your own answer before hints.

## Other lessons

These retain the document-led flow while we evaluate the pilot. Run `python3 scripts/curriculum.py status` from the repository root. It identifies the current lesson and record; for an unstarted lesson it shows a start command.

Follow the current lesson's instructions and its own preflight. Keep answers/results in the record or named artifact, without duplicate transcripts. Resume at the recorded stopping point rather than repeating finished reading or predictions.

The resource catalog, contract and supervision protocol are references. The lesson identifies any reading or action you need now.
