# M1-05 preflight

Create a small Rust package for enum and match practice. This page contains only M1-05 setup. The guiding agent may help with setup; that help is separate from the independent check.

## Open the working directory

In Terminal on your Mac:

```sh
cd /Users/mark/dev/repos/repos_private/syllabus
pwd
git status --short
```

Expect the syllabus directory. Preserve existing changes. There is no Linux setup for this lesson.

## Check only today's prerequisites

```sh
rustc --version
cargo --version
```

Expect each tool to print a version. Keep only a failed check's command/error in the attempt; do not produce a general capability inventory.

If the tools were previously installed, reopen Terminal and repeat the failed version command first. If still missing, install Rust here; M1-01's command-result pilot does not require it.

On your Mac, run `xcode-select --install` and complete Apple's Command Line Tools installer if those tools are missing. They supply the compiler/linker used to build Rust programs. If already installed, keep the existing installation.

Download the [official Rust installer](https://doc.rust-lang.org/book/ch01-01-installation.html) to a file:

```sh
mkdir -p "$HOME/syllabus-setup"
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs -o "$HOME/syllabus-setup/rustup-init.sh"
less "$HOME/syllabus-setup/rustup-init.sh"
```

$HOME is your Mac account's home directory. The script installs tools for that account and updates how the shell finds them. Have the agent review and explain it; press q to leave less. Then run without sudo:

```sh
sh "$HOME/syllabus-setup/rustup-init.sh"
. "$HOME/.cargo/env"
rustc --version
cargo --version
```

Choose the default stable installation. The dot command loads the tools into this terminal; expect versions from the last two commands. Keep the installer outside the repository. Retain a failed command/error for the agent to diagnose before initializing the package. Do not alter unrelated tool installations to clear a failure.

```sh
mkdir -p labs/m1-05 scratch/m1-05
```

These directories hold reviewed lesson artifacts and ignored temporary output, respectively. Keep existing files when resuming; preserve observations before a command using > replaces a capture.

If labs/m1-05/Cargo.toml is absent, initialize the standalone package:

```sh
cargo init --bin --name m1_05 --vcs none labs/m1-05
```

Cargo creates Cargo.toml (package settings) and src/main.rs (program source); --vcs none keeps this inside the existing Git repository. If the package exists, resume it without initialization. Keep source, Cargo.toml and the generated Cargo.lock; target/ build output stays ignored.
