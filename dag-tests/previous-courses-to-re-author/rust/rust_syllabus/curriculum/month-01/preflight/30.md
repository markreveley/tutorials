# M1-30 preflight

Prepare the existing demonstration and evidence for the final independent review. This page contains only M1-30 setup. The guiding agent may help with setup; that help is separate from the independent check.

## Enter Ubuntu and bring in committed work

On your Mac, from the repository root, review `git status --short` with the guiding agent. Save current lesson/session changes in a reviewed local commit (label incomplete work honestly) before transfer. A Git bundle carries commits, not unsaved or uncommitted edits. Keep working in one checkout at a time.

```sh
cd /Users/mark/dev/repos/repos_private/syllabus
multipass start syllabus-m1
mkdir -p scratch/lab-transfer
git bundle create scratch/lab-transfer/to-linux.bundle HEAD
multipass transfer scratch/lab-transfer/to-linux.bundle syllabus-m1:/home/ubuntu/to-linux.bundle
multipass shell syllabus-m1
```

Inside Ubuntu:

```sh
cd /home/ubuntu/syllabus
git status --short
git fetch /home/ubuntu/to-linux.bundle HEAD
git log --oneline HEAD..FETCH_HEAD
git diff --stat HEAD FETCH_HEAD
```

Review the incoming changes. With a clean Ubuntu checkout, run `git merge --ff-only FETCH_HEAD`. This advances the current branch only when the histories have not diverged. On dirty files or refusal, preserve both checkouts and ask the agent to reconcile them; do not reset or overwrite either. Replacing a transport bundle is safe only after its earlier commits have been imported.

## Check only today's prerequisites

```sh
uname -s
whoami
pwd
cargo --version
python3 --version
ip -Version
systemd-run --version
systemctl --version
ps -p 1 -o comm=
test -r /sys/fs/cgroup/cgroup.controllers && cat /sys/fs/cgroup/cgroup.controllers
```

Expect Linux, ubuntu, and /home/ubuntu/syllabus, followed by tool versions. Python must be 3.10 or newer. PID 1 must be systemd and cgroup.controllers must be readable (cgroup v2); the CPU and memory limits need cpu and memory controllers. Keep only a failed check's command/error in the attempt; do not produce a general capability inventory.

Use this section at session end, not before the exercise. Finish the lesson's exact-resource cleanup first. Review and commit the files listed in the lesson, including the attempt and agent-maintained progress; an incomplete commit is valid. In Ubuntu, from /home/ubuntu/syllabus:

The bundle saves committed work on the lab-work branch, not uncommitted changes. Back on your Mac:

```sh
cd /Users/mark/dev/repos/repos_private/syllabus
multipass transfer syllabus-m1:/home/ubuntu/from-linux.bundle scratch/lab-transfer/from-linux.bundle
git status --short
git fetch scratch/lab-transfer/from-linux.bundle lab-work
git log --oneline HEAD..FETCH_HEAD
```

After reviewing incoming changes, and only with a clean Mac checkout, run `git merge --ff-only FETCH_HEAD`. If either checkout has edits or the histories diverged, stop and ask the agent to preserve and reconcile both. Do not force an overwrite. Confirm `git log -1 --oneline` and inspect the transferred files before `multipass stop syllabus-m1` on your Mac. Stopping preserves the VM disk; do not delete the VM. Shutdown is housekeeping, not proof the exercise's cleanup worked.
