```sh
cd /Users/mark/dev/repos/repos_private/syllabus

```

## Check only today's prerequisites

```sh
rustc --version
cargo --version
```

Expect each tool to print a version. Keep only a failed check's command/error in the attempt; do not produce a general capability inventory.

If a previously installed tool is missing, reopen Terminal and repeat that version command. If it still fails, show the agent the error; have it repair that specific installation before the exercise. Do not initialize replacement source files to hide a tool failure.

```sh
mkdir -p labs/m1-09 scratch/m1-09
```

These directories hold reviewed lesson artifacts and ignored temporary output, respectively. Keep existing files when resuming; preserve observations before a command using > replaces a capture.

If labs/m1-09/Cargo.toml is absent, initialize the standalone package:

```sh
cargo init --bin --name m1_09 --vcs none labs/m1-09
```

Cargo creates Cargo.toml (package settings) and src/main.rs (program source); --vcs none keeps this inside the existing Git repository. If the package exists, resume it without initialization. Keep source, Cargo.toml and the generated Cargo.lock; target/ build output stays ignored.

```sh

```
