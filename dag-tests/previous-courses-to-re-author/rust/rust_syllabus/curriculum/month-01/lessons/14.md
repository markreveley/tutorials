## Exercise

1. Before running the guiding agent's three requests, trace each through validation, command construction, spawn, wait, and result handling. Explain ownership of request data and the child handle. Record predictions in `labs/m1-14/review.md`.

2. Run the supplied requests using your documented demo or tests. Preserve the exact executable, separate arguments, directory, synthetic environment, and observed outcome for each. Explain any disagreement with the prediction.

3. Independently change one test and one small behavior for the guiding agent's specified requirement. The requirement must use only concepts already practiced through M1-13. The guiding agent supplies inputs and requirements, not expected values or implementation.

4. State one remaining authority boundary in the runner. The guiding agent records the explanation and edit results separately and identifies any recovery task; successful execution alone does not pass this checkpoint.

Keep answers and results in the named checkpoint artifact. Under **Learner explanation**, briefly compare your result with your prediction and identify remaining uncertainty. Do not ask the agent to write the independent explanation.
