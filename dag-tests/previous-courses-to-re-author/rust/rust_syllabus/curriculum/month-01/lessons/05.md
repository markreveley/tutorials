## Exercise

1. In `labs/m1-05/src/main.rs`, write an `Outcome` enum with `Success`, `Failed(i32)`, and `NotStarted`, and a function that returns a readable message for each variant using `match`. An enum names a set of alternatives; a match chooses behavior for the alternative actually present. Keep values fixed in `main`; command-line parsing is not part of this lesson.

2. Add a label represented by `Option<String>`. `Some` carries a label; `None` represents its absence. Render the absent-label case explicitly. Agent implementation help is allowed during this exercise and must be recorded.

3. Use these four practice inputs: Success with a label, Failed(7) with no label, NotStarted with no label, and Success with no label. Predict the messages before `cargo run --manifest-path labs/m1-05/Cargo.toml`. Record actual messages in `labs/m1-05/README.md`.

4. Temporarily remove one match arm, run `cargo check --manifest-path labs/m1-05/Cargo.toml`, and retain the compiler error in the README. Explain the missing case before repairing it. Rerun `cargo check` after repair. This deliberate failure is practice; the independent check uses a different added variant.

Keep commands and actual results in the named evidence file; use the attempt's **Work and observations** for help received or a pointer to that file, not a duplicate transcript. Under **Learner explanation**, briefly compare your result with your prediction and identify remaining uncertainty. Implementation help during the exercise is allowed and must be recorded.
