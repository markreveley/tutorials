## Exercise

1. Create `labs/m1-06/examples/move.rs`: a `main` passes a `String` to a function taking `String`, then tries to use the original variable. Compile with `rustc labs/m1-06/examples/move.rs -o scratch/m1-06/move`. Record the compiler diagnostic before discussing a fix. A compile failure is expected here.

2. Preserve that failing file. Write separate `borrow.rs` and `return_owner.rs` versions: one changes the interface to borrow, the other gives ownership back to the caller. Compile each to a matching output name under `scratch/m1-06/` and run that executable. Explain each interface before accepting agent-proposed code; cloning is not a substitute for that explanation.

3. Add `conflict.rs`, attempting shared and mutable access whose uses overlap, and `scoped.rs`, with separated uses. Predict which compiles before invoking `rustc` with output paths under scratch. Preserve the failed source and diagnostic, then identify the last use of each borrow.
