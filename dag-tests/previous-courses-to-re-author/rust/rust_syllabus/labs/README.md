# Labs

Small standalone experiments go in labs/m1-NN/. Each lesson names its required artifacts. Create those paths as you work; their absence before the lesson is expected.

The [supplied fixtures](fixtures/README.md) remove repetitive workload setup. They do not implement the runner, namespace configuration, cgroup setup, or evidence reducer.

Use ignored scratch/ for transient files and raw captures. Commit a reviewed minimal reproduction and selected synthetic observations, not an entire terminal transcript.
