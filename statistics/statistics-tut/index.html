Statistics for Evals

The statistics you need to design evals, interpret uncertain results, compare agent versions, and defend a practical decision.

The professional target

Given an eval report, explain what it measures, whether the uncertainty calculation fits the data, and what decision the evidence supports.

Start with what statistics lets you say →

What you will be able to do

  • Define a score’s population, denominator, and run policy.
  • Read confidence intervals and compare systems on paired tasks.
  • Handle repeated runs, related repositories, missing outcomes, and task mixtures.
  • Evaluate a grader and inspect probability forecasts.
  • Plan sample sizes and avoid misleading comparisons or stopping rules.
  • Write an analysis and decision memo another engineer can reproduce.

How to work through it

This beginner course assumes percentages and averages, then builds the rest. Each lesson includes an eval scenario, worked reasoning, a pitfall, and a check with a revealable explanation. Selected lessons add terminal experiments where simulation makes the idea easier to see.

The running case compares two fictional agent versions. Start with independent tasks, then add repeated attempts, related repositories, and a sensitive category. All data are synthetic. Finish by defending a decision with a report template and a readiness rubric.

Practice locally

Open this file directly in a browser. Reading needs no server or packages. For terminal labs, use Python 3.9+ and run from this course directory:

python3 labs/stats_lab.py quiz
python3 labs/stats_lab.py compare

Try the interactive calculators, keep the math reference nearby, or use the command reference. The reading map offers shorter routes for reviewing results or designing an experiment.

Sources and scope

Original explanations and examples are supported by the annotated primary-source bibliography. The terminal code is deliberately small enough to inspect. It teaches statistical judgment and selected methods; it is not a general production analysis package.
