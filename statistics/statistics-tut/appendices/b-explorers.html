Appendix B

Interactive calculators

Change one assumption at a time. These local calculators show the arithmetic and name the model it depends on.

What does sample size do to an interval?

Start at 72/100. Then try 720/1,000, which keeps the observed rate fixed while increasing independent evidence. Finally try 10/10 and notice the lower bound. Read lesson 06 before interpreting the result.

Two-sided 95% Wilson interval. Assumes independent Bernoulli observations from the declared population; excludes measurement bias and distribution shift.

How many paired tasks?

Change a three-point target to six points. Then change the assumed SD of paired differences. The target is detection against zero, not a guarantee that the gain exceeds a deployment margin.

Large-sample approximation: independent pairs, two-sided alpha 0.05, power 0.8. Input SD must come from a justified model or pilot. Clustering and repeated looks require another design.

What does “three attempts” mean?

Compare at-least-one success with all-attempt success at a fixed hypothetical p. This is probability arithmetic for a known p, not an interval or the finite-sample pass@k estimator.

Assumes independent attempts with the same p for this task. Adaptive retries and shared state need an explicit model. Task heterogeneity means you must compute within tasks before averaging.

All calculations run in this page. There are no requests, accounts, or stored results.
