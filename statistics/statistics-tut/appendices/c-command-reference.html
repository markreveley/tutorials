Appendix C

Command reference and data schema

Every learner command uses local Python and the standard library. Run from the statistics-tut directory.

Start here

python3 --version
python3 labs/stats_lab.py --help
python3 labs/stats_lab.py quiz

Use Python 3.9 or newer. The quiz accepts 1, 2, 3, or q and prints explanations. Ctrl-C stops an experiment. No command in this table requires an API key, package installation, or network access.

Use a subcommand’s --help for options. Randomized commands accept --seed; compare also accepts --resamples, and correlate and screen accept --permutations. The correlate command enumerates every label ordering when n ≤ 8 and draws random orderings otherwise. The data path defaults are resolved relative to the script, so compare also works when invoked from another directory. An explicitly supplied relative path is relative to your current directory.

One task per line

{"task_id":"repo-01-task-0", "cluster_id":"repo-01",
 "slice":"routine", "a":[0,1,1], "b":[1,1,1]}

The example is wrapped for reading; each JSONL record occupies one line in the file. IDs and slice labels must be nonempty strings, task IDs unique, and score arrays nonempty lists of integer zeroes and ones. A/B attempt counts must match within a task. The schema intentionally rejects unknown scores instead of silently interpreting them as failures.

The CLI computes the mean within each task and gives each task equal weight. It does not require attempts to correspond by seed. With cluster mode, related task differences stay together, and the total task-weighted statistic is recomputed in each resample. The fixture notes describe all three datasets.

One candidate per line

{"candidate_id":"unit-003", "activation":[0.51, -1.2, ...],
 "label":[-0.45, -1.86, ...], "planted":true}

The activation and label lists must have the same length and at least three finite numbers. The optional planted flag lets the fixture report which rejections were false; omit it for your own data, and the screen output omits those columns. The screen command tests every candidate against its own label column; the fixture repeats one shared label in each record so that each line stands alone.

When to go beyond the teaching lab

General weights, ordinal scores, complex missingness, few-cluster corrections, crossed dependency structures, and production-scale data are outside this small implementation. The bootstrap is a nominal 95% percentile approximation. It is provided so you can read the code and understand what is resampled, not as a universal statistical package.

Command outputs used in authoring are retained in the verification transcript. For the formulas, see stats.py; for CLI policy, see stats_lab.py.
