Module 4 · Measure the measuring instrument

Evaluate the grader as a measuring instrument

A narrow interval around an unreliable grader’s score can make the wrong conclusion look convincing.

First define a reference judgment

A grader maps behavior to a label or score. To measure its quality, compare it with an independently adjudicated reference set under a written rubric. Human labels are measurements too: record disagreements, ambiguous cases, and adjudication rules. Let reference uncertainty remain visible rather than describing every human vote as unquestionable truth.

For this lesson, “positive” means a real failure that should be flagged. Choosing that orientation explicitly prevents confusion: a false negative is a missed failure; a false positive is a false alarm on acceptable behavior.

Read a confusion matrix

Consider an original hypothetical audit of 1,000 cases containing twenty reference failures.

Reference failureReference acceptable
Grader flags failure16 true positives49 false positives
Grader passes4 false negatives931 true negatives

Recall is the detected fraction of real failures: 16/20 = 80%. Precision is the real-failure fraction of flags: 16/65 ≈ 24.6%. Specificity is the correctly passed fraction of acceptable cases: 931/980 = 95%. Accuracy is all correct labels divided by all cases: 947/1000 = 94.7%. These definitions agree with the standard confusion-matrix metrics. [Metrics]

An always-pass grader achieves 98% accuracy here while detecting no failures. Accuracy rewards the common class heavily. You need the error types relevant to the decision, not a single unlabeled headline number.

Why precision changes with prevalence

Prevalence is the fraction of real failures in the population. Suppose the same 80% sensitivity and 95% specificity held in a population with 10% failures. Per 1,000 cases, you would expect 80 true flags and 45 false flags, so precision would be 80/125 = 64%. The grader’s conditional behavior is unchanged, but the mix of cases makes its flags more informative.

A failure-enriched grader audit is useful for estimating sensitivity. Its raw flag precision does not automatically estimate precision on ordinary traffic. To transport it, you need an appropriate prevalence and assumptions about conditional performance across populations. Oversampling rare failures is a sampling-design choice, not a reason to confuse the two populations.

Agreement is another question

When neither of two raters is a designated reference, report agreement rather than calling one “accurate.” Cohen’s kappa adjusts observed agreement pₒ by a chance-agreement quantity pₑ computed from the raters’ marginal label frequencies: κ = (pₒ−pₑ)/(1−pₑ). It is a descriptive agreement measure under that chance model, not proof of validity. It can be unstable or undefined with degenerate margins. [Agreement]

Two graders can agree because they share the same blind spot. Inspect disagreements and shared mistakes against the rubric. For ordinal ratings, weighting disagreements requires an explicit distance choice; for multiple raters or missing labels, choose an agreement method matching that design.

Check whether errors favor a version

Aggregate grader quality can hide differential error. If the candidate uses more confident language and the grader rewards that style, B may receive more false passes. Blind model identities where feasible, vary response order in pairwise judgment, and audit each version and important slice. Validation data used to tune the grader should be separated from its final audit.

In eval work

Report raw counts with recall and precision: 16/20 detected failures carries much less information than the 1,000-case headline suggests about failure recall. Uncertainty for each metric must reflect its effective denominator and the reference sampling design.

Pitfall

Assuming a grader that is 95% accurate must preserve a two-point model difference. Which cases it mislabels and whether mistakes differ by version can matter more than its aggregate accuracy.

Check your understanding

Two judges agree on 97% of outputs. Can you conclude either is 97% accurate?

Reveal the reasoning

No. Agreement has no truth reference by itself. They may share a systematic mistake or mostly see an easy majority class. Audit against a rubric-backed reference set, examine rare errors, and preserve human disagreement.

Practice

Recalculate all four metrics in the table. Then imagine an always-pass grader. State which error type matters if flags trigger human review versus automatic rejection.

What to look for

The always-pass grader has zero failure recall. Human-review capacity makes false alarms important; automatic rejection can impose additional costs on acceptable work. Both uses still require attention to missed important failures. Undefined precision when nothing is flagged should be labeled undefined, not silently invented.
