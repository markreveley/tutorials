Module 1 · Understand uncertainty

Bootstrap: repeat the analysis on resampled data

Use resampling to understand uncertainty while preserving the relationships your experiment created.

An empirical stand-in for the population

A bootstrap approximates sampling variation using the observed sample as a stand-in for the unknown distribution. Draw observations with replacement, recalculate the statistic, and repeat. “With replacement” means a sampled observation is eligible to be selected again. A resample can contain one original observation several times and omit another.

Observed independent units: [A, B, C, D] Example resample: [B, B, D, A] Next resample: [C, A, C, D] For each resample: calculate the same statistic again

A percentile interval takes the 2.5th and 97.5th percentiles of the bootstrap estimates for a nominal 95% interval. It is simple to inspect, which is why the teaching lab uses it. Other constructions, such as basic and BCa intervals, have different behavior; none removes the need to match the sampling design. [SciPy: bootstrap]

Choose what gets resampled

If A and B answered the same tasks, one independent unit contains both versions’ scores. Resample the pair together and recompute B−A. If tasks share a source repository, a unit may need to contain every task and both versions from that repository. The shape of the unit reflects what could have been independently sampled.

For a task-weighted average with unequal cluster sizes, resample clusters and recompute the total and task count for every draw. Averaging cluster means equally would target a different weighting. Our implementation concatenates the selected groups’ task differences before averaging, preserving this distinction.

Two types of randomness

The bootstrap resample count controls Monte Carlo error: how accurately the simulation approximates its own bootstrap distribution. The number of observed independent units controls how much evaluation evidence you have. Raising resamples from 4,000 to 40,000 does not turn 200 real tasks into 2,000 tasks.

A fixed random seed makes the computational experiment reproducible. It is not a statistical guarantee. With different seeds, endpoints can differ slightly. If they change enough to reverse a borderline decision, increase resamples and assess whether the underlying data support such a precise decision at all.

When a bootstrap cannot help

If every observed outcome is one, every ordinary resample is also all ones. The percentile interval collapses. Resampling cannot invent an unobserved failure or recover a missing task category. Sparse tails, very few independent groups, extreme quantiles, and biased samples need particular care.

Resampling all rows independently when they share repositories underestimates uncertainty from repository selection. Nesting another arbitrary bootstrap inside the first is not an automatic repair: the stages must match the actual sampling design. In our task-population analysis, observed task means are the units; we do not add a second within-task resampling step.

In eval work

Ask an analyst to describe one bootstrap draw in ordinary words. “Select repositories with replacement and keep each selected repository’s task pairs together” is assessable. “The library handles uncertainty” is not enough to review.

Pitfall

Calling a percentile interval “distribution free” as if it has no assumptions. Its usefulness still depends on the sample, independent units, statistic, and approximation quality.

Check your understanding

Your bootstrap uses 50,000 resamples but only six independent repositories. What did the larger resample count fix?

Reveal the reasoning

It reduced Monte Carlo noise in approximating the bootstrap distribution. It did not supply additional repositories or guarantee accurate coverage with six groups. More independently sampled repositories may be the more valuable next measurement.

Practice

Run the same paired analysis with two seeds. Identify which values must stay fixed and which can change. Read labs/stats.py to inspect a resample.

python3 labs/stats_lab.py compare --resamples 4000 --seed 7
python3 labs/stats_lab.py compare --resamples 4000 --seed 19
What to look for

Task counts and observed A, B, and B−A estimates stay fixed. Bootstrap interval endpoints can move because the simulated resamples change. This is computational randomness, not a new agent run.
