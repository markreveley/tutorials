Module 5 · Make defensible decisions

Design a comparison you can interpret

Good analysis begins with a protocol that separates the change you care about from the other things that can change a score.

What changed besides the model?

Suppose the baseline ran on Monday and the candidate on Friday. In between, the tool server changed, a cache warmed, and the grader prompt was edited. An observed difference cannot isolate the candidate’s effect from those changes. This is confounding: the factor of interest is mixed with other differences.

Holding configuration fixed, pairing tasks, resetting environments, and interleaving run order can reduce specific confounds. Blocking groups comparable runs under shared conditions; randomizing order within blocks helps avoid systematic alignment with time or load. These are applications of experimental-design principles. [NIST: design]

Decisions can change when new information arrives. Record amendments and whether results had already been examined. The purpose is to make the actual procedure inspectable, not to pretend an experiment never encounters surprises.

What regression can and cannot add

A regression models an outcome as a function of predictors. A linear model might include a candidate indicator, task category, and input length. Its candidate coefficient is a conditional association under that specification. Logistic regression models binary outcomes through log odds; its coefficients are not directly percentage-point changes.

Adjustment can improve precision or describe heterogeneity, but it does not automatically create causal identification. Unmeasured confounders, a wrong functional form, or conditioning on a quantity changed by the candidate can mislead. For example, controlling for number of tool calls may remove part of the candidate’s effect if changing tool use is the mechanism under study.

Start with a transparent paired comparison when it matches the design. Use regression when a defined modeling question warrants it, inspect diagnostics, and retain dependency-aware uncertainty. More predictors are not a substitute for an appropriate experiment.

Offline and online targets

An offline task eval estimates behavior on its task-selection and execution policy. An online randomized experiment can estimate effects in an actual user population, but needs a sensible assignment unit and outcome window. Repeated sessions from one user, shared resources, and spillovers between variants can violate simplistic independence assumptions.

A user-randomized rollout should not be analyzed as if every click were independently assigned. The same principle from task clusters applies: preserve the unit of assignment and the sources of dependence. Online evidence also needs its own monitoring and stopping plan.

In eval work

Preserve a machine-readable run manifest and a short human-readable analysis plan. The former lets you reproduce the measurement; the latter tells you why those measurements answer the decision question.

Pitfall

Calling an observational coefficient “the effect of the model” because the software printed a small p-value. The design, assumptions, and alternative explanations determine what causal claim is justified.

Check your understanding

You want to test a new retry policy, but you force both versions to use the same observed number of retries in the analysis. What could go wrong?

Reveal the reasoning

Retry count may be caused by the policy and its failures. Conditioning on it can change the target or introduce selection. Define whether you want the total policy effect at a common resource budget, a fixed-attempt comparison, or a different estimand before choosing the adjustment.

Practice

Use the report template to plan a comparison of two agent policies. Give each version the same task set, then specify reset, run order, stopping, and a realistic invalid-run rule.

What to look for

A good plan isolates the intended change, protects pairing, documents exceptions symmetrically, and names the independent unit. It also says which effect is worth acting on and how a critical regression affects the decision.
