Module 1 · Understand uncertainty

Probability, conditioning, and independence

Learn the small set of probability ideas that explains why an unchanged system can produce different scores.

A pass is a random variable

A random variable is a numeric outcome whose value is uncertain before observation. Let X be one if an agent passes a task and zero otherwise. If its pass probability under specified conditions is p, X has a Bernoulli distribution. With p = 0.7, the chance of a pass is 70%; a failure is still an ordinary possible outcome.

The expectation is the probability-weighted average of possible values. For this binary outcome, it is 1 × p + 0 × (1−p) = p. An expected value of 0.7 does not imply an individual attempt can score 0.7. It describes the average over repetitions of the experiment.

Specify the condition

Conditional probability restricts attention to some stated information. “Passes given a routine task” can differ from “passes given a sensitive task.” Suppose routine tasks are 80% of a hypothetical workload and pass with probability 0.9, while sensitive tasks are 20% and pass with probability 0.4.

P(pass) = 0.8 × 0.9 + 0.2 × 0.4 = 0.80

The overall pass probability is the weighted average of the two within-category probabilities. If the task mix changes, the overall rate changes even when behavior within each category stays fixed. This is why an evaluation needs a population description.

Conditioning also explains grader statistics. “The grader flags a failure given that a real failure occurred” is not the same as “a real failure occurred given that the grader flagged it.” Reversing the condition silently changes the denominator. You will work through that distinction in grader quality.

When can you multiply?

Independence means learning one outcome does not change the distribution of the other. Two independent attempts each passing with probability 0.7 both pass with probability 0.7 × 0.7 = 0.49. At least one passes with probability 1 − 0.3 × 0.3 = 0.91. We count “at least one” by subtracting the probability that both fail.

Without independence, use the conditional probability: P(A and B) = P(A) × P(B given A). A shared broken service, common source document, or leaked answer can connect outcomes. A different random seed does not remove every shared cause.

From attempts to a count

The number of passes in n independent Bernoulli trials with the same p follows a binomial distribution. Its expected count is np. In ten trials at p = 0.7, that is seven passes. It does not mean every batch contains exactly seven.

Task heterogeneity needs care. Conditional on a fixed collection of tasks, each task may have a different pass probability, so the total need not be binomial with one shared p. Independently sampling new task-and-attempt pairs from a stable mixture can instead produce binary observations with the same marginal p. The sampling story determines which model fits.

In eval work

Write the event precisely: “success on the next randomly selected task under this run policy.” A probability without its task distribution and conditions is easy to overgeneralize.

Pitfall

“Each call was separate, so the observations are independent.” Shared tasks, repositories, outages, sessions, and evaluators can produce dependence across separate calls.

Check your understanding

Two attempts have a 70% marginal pass rate. Can you conclude there is a 91% chance at least one passes?

Reveal the reasoning

Only with the needed independence and common-policy assumptions. If both outcomes always match, the chance of at least one pass is 70%. Inspect how retries share state and conditions before multiplying probabilities.

Practice

Predict whether every ten-task sample will score 70%. Run the simulation and inspect the histogram. Repeat with 100 trials.

python3 labs/stats_lab.py sample --p 0.7 --trials 10 --experiments 2000
What to look for

The simulator holds the true p fixed but observed rates vary. Larger independent samples concentrate more tightly. This simulator explicitly generates iid trials; that assumption must be justified for real eval data.
