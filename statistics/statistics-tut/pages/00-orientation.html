Module 0 · Ask a measurable question

What statistics lets you say

Learn to turn an eval result into a claim whose scope, uncertainty, and practical meaning you can explain.

The job is to defend an inference

You change an agent’s prompt and its pass rate rises from 72% to 78%. You now have several questions: did you test the same tasks, did the grader change, how much could the difference vary, and is the change worth its cost? Statistics gives you a language for answering these questions. It cannot choose the product’s priorities or rescue an eval that measures the wrong behavior.

An eval is a procedure: select tasks, run a specified system, observe its behavior, apply scoring rules, and summarize. A score is the end of that procedure. Your job is to understand the chain that produced it before interpreting its last number.

decision → target population → task selection → runs → grading → paired observations → uncertainty → scoped conclusion

Meet the running case

In this course, A is a baseline agent and B is a candidate. They are fictional. The first dataset contains 200 paired tasks, one attempt per version. A passes 144; B passes 156. Later you will use 120 tasks from 30 repositories with three attempts per version per task. Those tasks are deliberately related, and the candidate behaves differently on routine and sensitive work. All numbers are synthetic teaching examples, never claims about a real model.

Keeping the example small lets you inspect the underlying observations. A dashboard that only retains 72% and 78% has already discarded useful information. By the end, you will know which rows, identifiers, and run metadata to preserve.

Three professional abilities

  • Discuss: explain why a higher score can still leave a decision unresolved, without calling the result “just noise.”
  • Navigate: inspect a result file, find the independent unit, identify missing outcomes, and reproduce an estimate.
  • Design: choose a metric, task sample, run budget, comparison, and stopping rule before seeing the result.

The competence target is a ten-minute result review: given an eval report, identify what it estimates, whether the uncertainty calculation matches the data, and what decision the evidence supports. The final lesson asks you to write that review.

Start with ordinary arithmetic

You need fractions, percentages, and willingness to read a short formula. Every symbol is explained when introduced; there is no calculus prerequisite. The math reference is available whenever notation gets in the way. The sibling evals course explains what makes a good evaluation; this course develops the statistical reasoning behind its measurements.

Read the pages in order the first time. Predict an answer before opening each reasoning check. A mistaken prediction is useful: it tells you which assumption you were carrying. Terminal exercises use Python 3.9 or newer, its standard library, and local files. No model, API key, installation of packages, or network is needed. Every shown command assumes your terminal is in tutorials/statistics/statistics-tut.

In eval work

A good report says “B improved observed success by six percentage points on these paired tasks; the interval still includes some deterioration.” It separates the observation from the generalization and the action.

Pitfall

“Statistics will tell me which model is best.” It can quantify particular comparisons under particular assumptions. “Best” still requires a workload, priorities, and acceptable tradeoffs.

Check your understanding

A teammate gives you two percentages and asks which version to ship. What do you ask for first?

Reveal the reasoning

Ask for the task-level results and identifiers, task selection process, scoring and timeout policies, run configurations, and the decision threshold. You need to establish whether the scores answer the same question before choosing a test.

Practice

Open a terminal in the course directory. Inspect the available experiments, then try the six-question quiz as a baseline. It is fine to miss questions now.

python3 labs/stats_lab.py --help
python3 labs/stats_lab.py quiz
What to look for
