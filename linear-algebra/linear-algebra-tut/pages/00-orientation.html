Module 0 · Vectors

An activation is a vector

Every question this course answers is a question about vectors: where one points, how long it is, how much of it lies along a direction, and how a matrix moves it.

The object you will be studying

Run GPT-2 small on a sentence and stop it after the seventh transformer block. For each token it has produced a list of 768 numbers. That list is an activation, and the whole course is about what you can legitimately say about such lists. An interpretability claim of the form “this direction represents digits” is, concretely, a claim that one particular list of 768 numbers, dotted with the activation of each token, gives a larger number on digit tokens than on others. You cannot evaluate that claim without the dot product, and you cannot say what it would mean for the claim to be wrong without projections, bases, and a held-out check. Those are the contents of this course.

A vector is an ordered list of numbers of fixed length. The length of the list is the number of dimensions. Two numbers make a point in the plane; three make a point in space; 768 make a point in a space you cannot draw but can compute in exactly the same way. Every rule you learn on two dimensions, where you can check it with a pencil, carries over unchanged to 768. That is the pedagogical bargain of this course: each idea is shown first on a two-dimensional example you can verify by hand, then on the real 768-dimensional activations.

token → activation vector x ∈ ℝ⁷⁶⁸ → x · d (a scalar per token) → does it track a label?

The fixture: real activations, nothing simulated

The course ships one layer of GPT-2 small’s residual stream for 302 tokens of an original passage about a fictional harbour town, as labs/data/activations.npy with shape (302, 768). It also ships the four weight matrices of one attention head, so that the matrix lessons act on real maps rather than made-up numbers. The labels you will test directions against (“is this token a digit”, “does it follow a full stop”) were computed from the token strings, never from the activations. labs/data/README.md records how the file was produced and the two surprises it contains. Every number printed in these lessons was computed from that file; the transcript is in research/verify/lab-transcript.txt.

Why one layer? Because the moves do not depend on the layer. Why GPT-2 small? Because it runs on a laptop and is the model most of the published interpretability work you will read was done on. The sibling Python course shows how activations like these are cached with hooks; here they are simply loaded with numpy.

Shapes as a type system

If you write Elixir or Rust you are used to types that are checked before anything runs. Treat array shapes the same way. An activation has shape (768,). A batch of activations has shape (302, 768): 302 rows, one per token, each a 768-vector. A weight matrix that maps the 768-dimensional residual stream into a 64-dimensional head space has shape (768, 64). Before you compute anything, write the shapes and check that they compose; a shape error is a type error, and the lessons will keep writing shapes as comments next to code for that reason.

python3 labs/linalg_lab.py inspect
activations: shape (302, 768), dtype on disk float16, loaded as float32
tokens: 302; first eight: ['The', ' harbour', ' town', ' of', ' Weston', ' Hollow', ' kept', ' careful']
labels: is_digit (45 ones), after_period (23 ones), starts_with_space (241 ones), capitalised (29 ones)
token 12 = '42': first six of 768 coordinates [-2.182 -2.564  1.455  1.724 -1.904 -3.473]
  largest |coordinate| at index 447, value 41.81
head weights: W_Q (768, 64), W_K (768, 64), W_V (768, 64), W_O (64, 768)

Token 12 is the string '42', the second half of the year 1842, which the tokenizer split as ' 18' and '42'. Its activation begins −2.182, −2.564, 1.455, … and its largest coordinate, 41.81, sits at index 447. Keep that index in mind; it returns in lesson 06, where you will see that a large coordinate in the neuron basis is a fact about the basis as much as about the token.

The route through the course

Module 0 treats single vectors: adding and scaling them (lesson 01), measuring length and angle (02), and the central move of projecting onto a direction (03). Module 1 treats matrices as maps: shapes (04), multiplication as composition and as batching (05), bases (06), and rank (07). Module 2 removes a direction cleanly (08) and fits a direction to labels (09). Module 3 reads the spectrum of a matrix: eigenvectors of a symmetric matrix (10), PCA on the activations (11), and the SVD of a weight product (12). Module 4 adds the calculus minimum (13) and the question that decides whether any of this was real (14), then the readiness review (15).

There are no proofs. There are checks: numerical identities you can run, such as that a residual is orthogonal to its direction or that the squared norms of a projection and its residual add up to the squared norm of the original. When a lesson states a rule, the lab prints the check. If you want the proofs later, the reading map points to the 3Blue1Brown chapter for each lesson, which supplies the geometric argument.

In interpretability work

“The model represents X along direction d” is a sentence about a dot product. Before accepting it, you will want to know the scale of d, what the projection looks like on tokens that were not used to find d, and what a random direction would have scored. By lesson 14 you will be able to ask all three.

Pitfall

Treating the 768 coordinates as 768 meaningful quantities. They are coordinates in one basis, chosen by how the weights happen to be stored. Lesson 06 shows the same activation written in a different basis with entirely different numbers and the same length.

Check your understanding

A colleague says “the activation for the token 42 has a big value in dimension 447, so dimension 447 must be doing something about numbers.” What two things would you want to check before agreeing?

Reveal the reasoning

First, whether dimension 447 is large for every token, not only numbers; the inspect output cannot tell you, but lesson 02 shows the same index dominates the fixture’s mean. Second, whether “dimension 447” is a direction with any privileged meaning at all: it is one axis of the neuron basis, and lesson 06 shows that the residual stream can be rotated into another basis without changing the model. A claim about numbers needs a direction found from the number label and tested on tokens not used to find it.

Practice

List the lab commands, then inspect token 0. Compare its largest coordinate with token 12’s.

python3 labs/linalg_lab.py --help
python3 labs/linalg_lab.py inspect --token 0
What to look for

Token 0 is the word “The” at position 0, and its largest coordinate is enormous compared with token 12’s 41.81. Lesson 02 measures it: the first token’s vector is about thirty-six times longer than a typical token’s. Most later commands exclude position 0 and say so.
