Module 4 · Calculus and rigor

Gradients as directions

The gradient of a scalar function of a vector is itself a vector: the direction of steepest increase. For a dot product it is a constant, for a norm it is a unit vector, and that is most of the calculus this work needs.

The derivative of a dot product

Let f(v) = v · d for a fixed direction d. Change v by a small vector h and f changes by (v + h) · d − v · d = h · d, exactly, with no small-term approximation, because the dot product is linear. The gradient ∇f is the vector g such that the change in f for a small step h is g · h to first order, so for the dot product ∇f = d, a constant vector that does not depend on where you are. Coordinate by coordinate, ∂f/∂vᵢ = dᵢ, which you can read off from f = Σ vᵢ dᵢ.

f(v) = v · d ⇒ ∇f = d
f(v) = ‖v‖ = √(v · v) ⇒ ∇f = v / ‖v‖ (undefined at v = 0)
f(v) = ‖v‖² = v · v ⇒ ∇f = 2v
f(v) = v · d / ‖d‖ ⇒ ∇f = d̂ (the projection coefficient; gradient is the unit direction)

For the squared norm, f = Σ vᵢ², so ∂f/∂vᵢ = 2vᵢ and ∇f = 2v. For the norm itself apply the chain rule to the square root: ∇‖v‖ = (1 / (2‖v‖)) · 2v = v/‖v‖, the unit vector pointing along v. The norm grows fastest if you keep going the way you were going, at rate one. That is the entire derivation, and it is the only chain-rule computation in the course.

Gradient as direction

A gradient is a vector in the same space as v, and it answers a geometric question: of all unit directions u, which makes f increase fastest for a tiny step? The answer is u = ∇f/‖∇f‖, and the rate of increase in direction u is ∇f · u, a projection coefficient (lesson 03). Stepping along the gradient is gradient ascent; stepping against it is gradient descent, the procedure that trained every weight in the fixture. For f(v) = v · d̂ the gradient is d̂, a step of length s along it increases the projection coefficient by exactly s, and a step of the same length in a direction orthogonal to d̂ changes it by zero.

The lab checks the two analytic gradients against central finite differences, (f(v + hεᵢ) − f(v − hεᵢ)) / 2h, on the first five coordinates of a real activation, then takes one ascent step.

python3 labs/linalg_lab.py gradient
token 12 '42'; f(v) = v.d with d the digit direction
analytic gradient of v.d is d; first five entries [0.753 0.62  2.768 0.615 1.665]
numeric gradient (central differences) on those five coordinates [0.753 0.62  2.768 0.615 1.665]
analytic gradient of |v| is v/|v|; first five [-0.025 -0.029  0.016  0.019 -0.022]
numeric on those five coordinates [-0.025 -0.029  0.016  0.019 -0.022]
gradient ascent on f(v) = v.d/|d|: coefficient 19.71 -> 24.71 after a step of length 5.0 (predicted increase exactly 5.0)
same step length in a random direction: 19.71 -> 19.52
norm after the step along d: 88.51 -> 89.75; cos(x, d) = 0.223

The numeric and analytic gradients agree to the printed precision in both cases. The ascent step is the formula box made concrete: a step of length 5 along d̂ raised the projection coefficient from 19.71 to 24.71, exactly 5, while a step of length 5 in a random direction moved it by −0.19, the random direction’s small chance component along d̂. The norm grew only from 88.51 to 89.75, because the step was mostly orthogonal to x (their cosine is 0.223); by Pythagoras, ‖x + 5d̂‖² = ‖x‖² + 2·5·(x · d̂) + 25 = 7,833.8 + 197.1 + 25 = 8,055.9, and √8,055.9 = 89.75.

Where this is used

Three places, all the same computation. Attribution: the gradient of a scalar output, such as a logit or a probe score, with respect to an activation is a vector in activation space; its dot product with a change in the activation predicts, to first order, the change in the output, so gradient-times-activation is a first-order estimate of each component’s contribution. Feature visualisation and steering: gradient ascent on an input or an activation to maximise a scalar is repeated steps along ∇f, and the lesson’s step is one iteration of it with f linear. Training: every weight in W_Q was set by gradient descent on a loss, which is why the fixture exists. In a framework such as PyTorch the gradient is computed for you by backpropagation; this lesson is so that you can check one by hand and know what shape it must have: the gradient of a scalar with respect to a (768,) activation is a (768,) vector, with respect to a (768, 64) matrix is a (768, 64) matrix.

In interpretability work

Gradient-based attribution assumes the first-order approximation is good over the size of change considered. For a linear function such as a projection it is exact, as the output shows; for a model with nonlinearities it is exact only for infinitesimal steps, and the check is to take the actual step and compare. The interpretability course makes that comparison on real attribution methods.

Pitfall

Reading the gradient of the norm as “the direction the model wants to grow”. ∇‖v‖ = v/‖v‖ is a fact about the norm function and holds for any vector whatsoever; it carries no information about the model. A gradient is interesting when the function is, and the dot product with a fixed direction is interesting only when the direction is.

Check your understanding

f(v) = (v · d̂)² is the squared projection coefficient. What is its gradient at a real activation x, and in which direction does it point?

Reveal the reasoning

By the chain rule on g(v) = v · d̂ with ∇g = d̂, ∇f = 2 (v · d̂) d̂ = 2c d̂, where c is the current coefficient. It points along d̂ when c is positive and against d̂ when c is negative: squared projection grows by moving further from the hyperplane c = 0 in whichever direction the token is already on. Its magnitude 2|c| is zero on that hyperplane, where the function has its minimum.

Practice

Token 147 (' a') was the least digit-like token in lesson 02. Take the same ascent step from it and verify the predicted increase of 5.0.

python3 labs/linalg_lab.py gradient --token 147
What to look for

The coefficient rises by exactly 5.0 again, from wherever it started, because the gradient of a linear function is the same everywhere. The starting coefficient will be negative. Whether adding 5d̂ to the activation of “a” would make the model behave as if it saw a digit is a question about the model, not about this arithmetic, and only an intervention experiment answers it.
