Linear Algebra for Interpretability

The dot products, projections, matrix products, PCA and SVD you need to read activations as vectors, shown on real GPT-2 small activations.

The professional target

Given a cached activation matrix and a label vector, find a direction, measure its projection on held-out tokens, run PCA and SVD, and say in plain words what every number means and what it does not.

Start with why an activation is a vector →

What you will be able to do

  • Read an activation vector, a weight matrix, and a batch of activations as shapes, and predict the shape of any product before computing it.
  • Project activations onto a direction and explain what the scalar per token measures.
  • Say why a direction need not be a neuron, and what rank and near-orthogonality mean in 768 dimensions.
  • Remove a direction from activations and know what that does and does not erase.
  • Fit a direction to labels by least squares and check it on tokens you did not fit on.
  • Run PCA and SVD on an activation matrix and on a weight product, read the variance explained and the singular values, and name what they do not tell you.
  • Compute the gradient of a dot product and a norm, and test whether a correlation with a direction is real.

How to work through it

The course assumes no linear algebra. It assumes you write programs, can follow a short argument, and want the geometry rather than the proofs. Every idea is shown twice: once on a two-dimensional example you can draw, then on real activations from GPT-2 small cached in labs/data/. Each lesson ends with a reasoning check and a practice command whose output is reproduced from a saved transcript.

The fixture is one layer of the residual stream for 302 tokens of an original passage, plus the four weight matrices of one attention head. Nothing is simulated. The first token has an activation about thirty-six times larger than the others; the lessons use that fact rather than hide it.

Practice locally

Open this file directly in a browser. Reading needs no server or packages. For the labs you need Python 3.10 or newer and numpy; torch is needed only to regenerate the fixture, which is already included. Run from this course directory:

python3 labs/linalg_lab.py --help
python3 labs/linalg_lab.py inspect
python3 -m unittest discover -s labs -p 'test_*.py' -v

The exercises live in labs/linalg.py as stubs; the tests skip until you implement each one. Try the projection and SVD explorers, keep the notation reference nearby, use the command reference, and follow the reading map to the matching 3Blue1Brown chapter and ARENA exercise for each lesson.

Part of your interpretability curriculum

This course sits between Python for Model Internals, which teaches how the fixture was cached, and Transformer Anatomy, which uses these matrices inside attention. Interpretability Methods and Rigor turns the final lessons into prediction tests on neurons and features, and the statistics course supplies the uncertainty language that lesson 14 only sketches.

Sources and scope

Pure mathematics is explained without citation. Statements about models are either stated as geometry or cited to the annotated bibliography. The lab code is small enough to read in one sitting; it teaches the moves, it is not a library.
