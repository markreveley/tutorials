Appendix C

Command reference

Every lab command, its options, and the lesson it belongs to. All run from the course directory with numpy only.

Running the labs

python3 labs/linalg_lab.py --help
python3 -m unittest discover -s labs -p 'test_*.py' -v

The CLI uses labs/reference.py, so every command works before you implement anything. The tests exercise your labs/linalg.py: a test whose function still raises NotImplementedError is reported as skipped with the function’s name. The same tests also run against the reference (labs/test_reference.py), along with fixture integrity and CLI checks, so a fresh checkout shows 44 tests with 18 skipped. Every command’s actual output is in research/verify/lab-transcript.txt.
