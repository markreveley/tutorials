Vectors (lessons 01–03)

u + v = (u₁ + v₁, …); c·u = (c·u₁, …)
u · v = Σᵢ uᵢvᵢ; ‖u‖ = √(u · u); cos θ = u · v / (‖u‖ ‖v‖)
projection coefficient c = v · d̂; projection p = c d̂; residual r = v − p, with r · d = 0 and ‖p‖² + ‖r‖² = ‖v‖²
batch: X d̂ has shape (n,), one coefficient per token

Maps (lessons 04–07)

(x W)ⱼ = x · (column j of W); (n, k)·(k, m) → (n, m)
(AB)C = A(BC); AB ≠ BA in general
einsum: 'nd,dh->nh' is X W; 'nh,mh->nm' is Q Kᵀ; a letter absent from the output is summed
coordinates in basis B (columns): solve B c = v; if B is orthonormal, cᵢ = v · bᵢ and ‖c‖ = ‖v‖
rank(AB) ≤ min(rank A, rank B); rank of (n, d) ≤ min(n, d)

Subspaces and fitting (lessons 08–09)

Gram–Schmidt: wₖ = vₖ − Σⱼ<ₖ (vₖ · qⱼ) qⱼ; qₖ = wₖ / ‖wₖ‖
remove d from every row: X − (X d̂) d̂ᵀ = X (I − d̂ d̂ᵀ)
least squares: minimise ‖X w − y‖²; normal equations XᵀX w = Xᵀy; ridge (XᵀX + λI) w = Xᵀy
centred fit: w from X_c, y − ȳ; intercept b = ȳ − x̄ · w

Spectra (lessons 10–12)

A v = λ v; symmetric A = V Λ Vᵀ with orthonormal V
covariance C = X_cᵀ X_c / (n − 1), shape (d, d); Var(X_c u) = u · C u for unit u
PCA: components = eigenvectors of C in decreasing λ = rows of Vᵀ from the SVD of X_c; explained(i) = λᵢ / Σλ; scores = X_c Vₖᵀ
SVD: A = U Σ Vᵀ = Σᵢ σᵢ uᵢ vᵢᵀ; A vᵢ = σᵢ uᵢ; σᵢ² are eigenvalues of AᵀA
best rank-k: Aₖ = Σᵢ≤ₖ σᵢ uᵢ vᵢᵀ; ‖A − Aₖ‖² = Σᵢ>ₖ σᵢ²

Gradients and correlation (lessons 13–14)

∇(v · d) = d; ∇‖v‖ = v/‖v‖; ∇‖v‖² = 2v; ∇(v · d̂)² = 2 (v · d̂) d̂
central difference: ∂f/∂vᵢ ≈ (f(v + hεᵢ) − f(v − hεᵢ)) / 2h
corr(a, b) = (a − ā) · (b − b̄) / (‖a − ā‖ ‖b − b̄‖)
