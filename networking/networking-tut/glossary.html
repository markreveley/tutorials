Reference · Vocabulary

Glossary

Plain-language definitions for the course. Dashed-underlined terms in lessons show a short definition and link here.

ABCDEFGHIJKLMNPQRSTUVW
A

API

Application Programming Interface: a contract for interacting with software. A network API adds application rules above its underlying protocols.

ARP

Address Resolution Protocol: a mechanism for finding a local-link address for a directly reachable IPv4 destination, commonly the next-hop router.

Attempt

One execution of a request or operation. Several attempts may belong to one logical evaluation sample.

Authentication

Establishing an identity. TLS server identity and the client’s API identity are separate authentication questions.

Authorization

Deciding what an identified caller is permitted to do. A reachable service can still reject an authenticated request.

Availability zone

A provider-defined isolated deployment location within a region. Specific failure and placement guarantees depend on the cloud provider.

B

Backpressure

Slowing or limiting upstream production when downstream capacity is constrained, so waiting and resource use stay bounded.

Bandwidth

A capacity for carrying data, commonly measured in bits per second. It differs from achieved throughput and from latency.

C

Certificate

A signed statement binding identity information to a public key under a trust system. Clients validate the chain, name, dates, and applicable rules.

CIDR

Classless Inter-Domain Routing notation represents an address prefix using an address and slash length. In IPv4, /24 leaves eight bits for addresses in the range.

Circuit breaker

A policy that temporarily stops calls to a failing dependency and controls recovery probes. It is not a substitute for recording failed or unattempted work.

Client

A program acting as the initiator of a request. The same program can be a client on one connection and a server on another.

CNAME

A DNS record that makes one name an alias for another canonical name. Resolving the alias can require additional lookups.

Concurrency

The number of operations active at the same time. It is not a rate per minute and does not by itself enforce a provider quota.

Congestion control

Mechanisms that adapt sending to shared network capacity. They are different from application quotas such as requests per minute.

Connection pool

A finite set of reusable client connections. Pool waiting and connection establishment are different contributors to elapsed time.

Container

An isolated process environment using operating-system facilities. Its networking depends on namespace and runtime configuration, not merely on its image.

CORS

Cross-Origin Resource Sharing: browser-enforced rules governing a page’s access to responses from other origins. curl success does not establish browser permission.

D

Deadline

A time budget or cutoff for an operation. An end-to-end deadline must account for its included waits and retries.

DNS

The Domain Name System: a distributed system for looking up records associated with names. Resolving an address does not prove the application is reachable.

E

Egress

Traffic leaving an environment. An eval worker’s outbound model request is egress from the worker network.

Encapsulation

Wrapping higher-level data in a lower-level protocol’s headers or other framing. Receivers interpret the layers in reverse order.

EndpointSlice

A Kubernetes object describing network endpoints associated with a Service. Checking it helps distinguish a Service name from usable backend targets.

F

Flow control

Mechanisms preventing a sender from overwhelming the receiver’s available capacity. In TCP this is distinct from protecting shared network capacity.

Frame

A unit sent over a link-layer network, such as Ethernet. A frame can carry an IP packet as its payload.

G

Gateway

A system connecting or mediating between environments. A default IP gateway forwards packets; an API gateway applies application-level policy. Ask which meaning is intended.

gRPC

An RPC framework commonly using HTTP/2 and Protocol Buffers. Its application status must be interpreted in addition to the HTTP exchange.

H

Handshake

An exchange used to establish connection state or security parameters. TCP and TLS have different handshakes.

Header

A field carrying message metadata, such as Content-Type or Authorization. Some headers are sensitive and should be redacted from diagnostics.

Host

A computer participating in a network. A host can run many processes and have several network interfaces.

HTTP

Hypertext Transfer Protocol: application-level request/response semantics, including methods, fields, and status codes. HTTP versions differ in framing and transport.

HTTPS

HTTP using a secure transport with server authentication. Successful HTTPS does not guarantee API authorization or a correct model answer.

I

Idempotency

The property that repeating an operation has the same intended effect as performing it once. It does not imply identical responses or zero additional cost.

Ingress

Traffic entering an environment. Kubernetes also uses Ingress as the name of an API object describing incoming HTTP routing.

IP address

An Internet Protocol address used for delivery in a particular network context. An address does not by itself identify a person or grant permission.

IPv4

The widely used version of IP with 32-bit addresses, usually written as four decimal octets. Private and public addressing have different routing contexts.

IPv6

The version of IP with 128-bit addresses. A service can have IPv4 and IPv6 paths with different reachability.

J

Jitter

In retry policies, randomized delay that reduces synchronized retries. In network performance discussions, it can instead mean variation in delay.

K

Kubernetes Service

An abstraction for accessing a set of backends. A typical ClusterIP Service provides stable cluster-internal access, but other Service types and headless Services exist.

L

Latency

Elapsed time for a defined operation. Always name the boundaries: connection setup, first token, completed response, or whole logical sample.

Listener

A server socket waiting for incoming connections on a bound address and port. A running process may have no listener, or may listen only on loopback.

Load balancer

A component distributing traffic across backends. Its decision unit may be a connection or an application request, depending on its layer and implementation.

Localhost

A conventional hostname for loopback. Inside a container or Pod, its meaning follows that environment’s network namespace.

Loopback

An interface for communication within the local network environment. 127.0.0.1 is an IPv4 loopback address; ::1 is its familiar IPv6 counterpart.

M

mTLS

Mutual TLS: TLS with certificate-based client authentication as well as server authentication. It is not automatically used by ordinary API-key-based HTTPS.

MTU

Maximum Transmission Unit: the largest network-layer packet size carried on a link without link-specific fragmentation. Tunnels and other encapsulation can reduce the usable size.

N

NAT

Network Address Translation: rewriting address information, often with port mappings so multiple private clients can share public IPv4 addresses.

NCCL

NVIDIA’s library for collective communication among GPUs. Its internal traffic is distinct from the external HTTPS path to a model endpoint.

Network namespace

An isolated view of networking resources such as interfaces, routes, and sockets. Containers can have separate namespaces or deliberately share one.

NetworkPolicy

A Kubernetes object constraining selected traffic flows when enforced by a supporting network plugin. Its presence alone does not prove enforcement.

NXDOMAIN

A DNS response indicating that the queried name does not exist according to that response. It is distinct from a resolver failing to answer.

P

Packet

A bounded unit of data carried by a network protocol, such as an IP packet. An application message can span many packets.

Percentile

A value locating an observation within a distribution under a chosen convention. Tail percentiles need enough observations and a clear failure-handling policy.

Pod

A Kubernetes unit whose containers share networking and some other resources. localhost can connect containers in the same Pod, not arbitrary Pods.

Port

A transport-level number that helps distinguish communication endpoints on a host. TCP port 443 and UDP port 443 are different protocol endpoints.

Process

A running program. A server process must listen on an address and port to accept network connections.

Protocol

An agreement about message formats and behavior between communicating participants, including what they send and how they respond.

Proxy

An intermediary handling traffic on behalf of a caller or service. It can affect destinations, security boundaries, buffering, timing, and error responses.

Q

QUIC

A secure transport over UDP that supplies streams and congestion control. HTTP/3 uses QUIC instead of TCP.

R

Rate limit

A restriction on work over time, such as requests or tokens within a policy window. Limits can apply across many workers or clients.

Region

A provider-defined geographical deployment area. Different regions can imply different routes, latency, availability assumptions, and transfer costs.

Request ID

An identifier supplied or propagated by a component for correlating a request with logs. Different systems may use different IDs for the same logical sample.

Resolver

Software that performs name lookups. A recursive DNS resolver can obtain answers from other DNS servers and cache them.

Retry

Another attempt after an outcome that the policy deems retryable. It can duplicate work and should retain its own attempt identity.

Route

A forwarding rule connecting a destination prefix to a next hop or interface. A route alone does not prove permissions or a working return path.

Router

A device or system forwarding traffic between IP networks. Forwarding commonly uses the most specific matching destination prefix.

RPC

Remote Procedure Call: a style of invoking an operation on another process or machine. Failures can leave uncertainty about whether remote work happened.

RTT

Round-trip time: elapsed time for a network exchange to go to a destination and back. It is not the same as total model response time.

S

Sandbox

An environment that constrains code or tool execution. Its filesystem, identity, and network permissions are part of an agent evaluation’s task conditions.

Security group

In AWS, a stateful allow control associated with resources. It is separate from route tables, network ACLs, and application authorization.

Server

A program or machine providing a service to clients. Context tells you whether someone means the process, machine, or whole service.

SNI

Server Name Indication: TLS information identifying the hostname the client intends to contact, allowing servers to select appropriate configuration and certificates.

Socket

An operating-system communication endpoint used by a process. Network sockets are associated with protocols and addresses; not every socket uses IP.

Span

A timed operation within a trace, with identifiers and attributes that help relate it to other operations.

SSE

Server-sent events: a text event-stream format commonly used for server-to-client streaming over HTTP. Event framing and application completion are separate concerns.

Subnet

An address range and associated network subdivision. Provider rules determine which addresses can be assigned to resources.

Switch

A device commonly used to forward frames within a link-layer network. Modern hardware may also route IP traffic, so the exact role matters.

T

TCP

Transmission Control Protocol: a transport that supplies an ordered, reliable byte stream while a connection is usable. It does not guarantee application completion.

Throughput

The achieved rate of useful work, such as completed samples per second. Specify whether you count attempts, logical samples, bytes, or tokens.

Time to first token

Elapsed time until the client identifies the first generated content token or event under a stated measurement definition. It is distinct from first byte and completion latency.

Timeout

A limit on a particular wait. Library semantics vary; distinguish connection, pool, idle-read, and total-operation limits.

TLS

Transport Layer Security: a protocol providing protected communication and authentication mechanisms. HTTPS normally validates the server’s identity through certificates.

Trace

Related observations representing a request’s path through operations. A distributed trace depends on instrumentation and propagated context.

TTL

Time to live. In DNS, a cache lifetime for a record. In IP discussions, TTL refers to a different field limiting packet lifetime through hops; do not confuse the two.

U

UDP

User Datagram Protocol: a transport for datagrams without built-in guarantees of delivery or order. Higher-level protocols can add reliability over it.

V

VPC

Virtual Private Cloud: AWS terminology for a configurable virtual network. It contains addressing and connectivity configuration, not automatic trust or encryption.

W

WebSocket

A protocol for bidirectional messages over a persistent connection. It differs from SSE and from raw TCP read boundaries.
