A reading method

Before a section, write the question you want answered. After it, explain one implication for the eval worker and one thing the protocol does not guarantee. Follow unfamiliar words into the glossary; return to packet-level details when a concrete problem calls for them.

The book provides a systems foundation. Product-specific routes, Kubernetes objects, curl flags, and GPU libraries require the official documentation linked in the course. The original exercises apply those principles to eval work; they are not claims that the textbook prescribes a particular eval architecture.
