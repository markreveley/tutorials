Network calculators

Small, local calculators for checking intuition. These are simplified teaching models, not measurements of your network.

Read an IPv4 prefix

Enter an IPv4 address and prefix length. The calculator normalizes the network prefix and shows the inclusive range. Address count is not usable-host count: operating systems, cloud providers, and subnet types reserve or interpret addresses differently.

Check your understanding

Which contains more addresses: /16 or /24?

Reveal the reasoning

/16 leaves 16 variable bits and describes 65,536 addresses. /24 leaves eight variable bits and describes 256. The shorter fixed prefix covers the larger range. A /32 describes one IPv4 address; /0 covers the entire IPv4 address space.

Compute a serialization lower bound

Formula: seconds = MB × 8 / Mb per second. This ignores propagation, queueing, handshakes, protocol overhead, other traffic, and server computation. Do not add overlapping stages twice. MiB and GiB are binary units; these inputs deliberately use decimal MB and Mb.

Estimate average in-flight work

Formula: average in-flight work = throughput × mean time in system. It applies to a stable system with matching measurement boundaries. The result is neither a safe production setting nor a guarantee of throughput. Count queue time if the population includes queued work; exclude it consistently if measuring only active requests.
